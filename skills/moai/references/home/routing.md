## MoAI

For a development request — build, fix, review, research, or set up or update a project — use the `moai` skill ({invoke}). It picks the route from its `references/routes.json` and the agent order from `references/chains/index.md`; the base agents moai-plan, moai-research, moai-impl, moai-audit and moai-docs are installed beside it.

- Answer from the repository, a command or a document before asking.
- The agent that implemented a change never audits it.

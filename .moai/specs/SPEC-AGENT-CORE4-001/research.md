## §6 Claude facts that shape the hiding (official documentation, fetched 2026-10-18)

- `code.claude.com/docs/en/skills`: `skillOverrides` takes "Each key is a skill name"; no wildcard
  is documented. States: `on`, `name-only` (name listed, description not loaded), `user-invocable-only`
  (hidden from Claude, visible in `/`), `off` (hidden from Claude and from `/`).
- `code.claude.com/docs/en/sub-agents`: "You can't preload skills that set `disable-model-invocation: true`,
  since preloading draws from the same set of skills Claude can invoke"; "If a listed skill is missing
  or disabled ... Claude Code skips it and logs a warning to the debug log". The page does not say
  whether `off` counts as disabled, and says nothing on `user-invocable: false`.
- Therefore the redesign's default (`"moai-agent-*": "off"`) is doubly unverified: the wildcard is
  undocumented and `off` may block preload. REQ-AC4-017/018 follow from this.
- Installed runtime: `claude --version` → `2.1.302 (Claude Code)`; changelog snapshot 2.1.292 records
  "`skillOverrides` setting now works" (`.moai/research/cc-changelog-snapshot-2.1.292.md:5027`).

## §7 Hook and record facts

- Spawn audit record today (`internal/hook/agent_model_guard.go:132`): `timestamp`, `session_id`,
  `agent`, `declared_model`, `resolved_model`, `verdict`, `override_consumption`. No phase, effort,
  or prompt size (`grep -c 'prompt_bytes' internal/hook/agent_model_guard.go` → 0, exit 1). The
  prompt body is read in memory only and never logged (file header contract). The Agent tool accepts
  `effort` since CC 2.1.292 (`agent-common-protocol.md` § Subagent Model and Effort).
- PreToolUse family in `internal/hook` (branch guard, agent-model guard, agent-stop guard) denies
  only on positive evidence and fails open elsewhere; sentinels precede every deny reason
  (`BRANCH_GUARD_VIOLATION`, `STOPPED_TEAMMATE_VIOLATION`). The identity of the acting agent is
  `agent_type` on the PreToolUse payload (measured note in `main-checkout-branch-guard.md`: the
  value is the spawn name verbatim).
- `moai memory` verbs: `doctor`, `archive`, `drain`, `fold`; the PostToolUse mirror watches
  `.claude/agent-memory/**/*.md`. No byte cap is enforced anywhere.
- `moai agent` has one verb, `lint`. `moai agent size --json` → `Unknown flag: --json.` exit 1
  (RED-now for AC-AC4-001).
- Ownership lint: `internal/spec/lint_ownership.go` maps the trailer values `manager-spec`,
  `manager-develop`, `manager-docs`, `manager-git`, `orchestrator-direct` to transition owners.

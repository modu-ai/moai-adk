# Inventory: what still sends `moai` to the Go build

Read 2026-11-19/20 (UTC clock read with `date -u`). Everything here comes from commands and file reads of this task; nothing was changed. Written for SPEC-20261119-rust-only-moai.

## Summary

- Words the v2 shim routes to Go: 60 on its Go line (59 real words + `bundle`), plus the `spec` (7), `session` (7) and `bundle` (3) actions it splits. Rows: 59 words + 17 actions.
- Word table: rust-has 16, port 2, retire 41. Action table: rust-has 7, port 0, retire 10.
- `moai` and `that` on the shim's Go line are not Go commands (Go answers "Unknown command"): dead entries.
- `bundle` is the only word both builds have: the shim sends the whole word to Go, so Rust `bundle build|verify|ready|check|body` reaches Go (which has none of those) when called as `moai bundle …`.

### Decisions this list hands to the leader and the user

1. **`gate` (port).** The git pre-commit hook the Go build installed runs `MOAI_PRECOMMIT=1 moai gate` in 13 repos under `/Users/goos/MoAI`; `moai-cli gate` exits 2, so with no Go every commit in those repos is blocked. Options: a thin Rust `gate` that does the skip-and-pass path (about 9 Go lines), or replace the Go-installed git hooks per project.
2. **`mcp-server` (port).** 10 projects register `moai mcp-server` in `.mcp.json`; Rust has no MCP server (Go: 11,547 lines in 30 files, 22 tools). Port it, or retire it together with the 10 registrations.
3. **`verify` (retire, decision point).** One live caller on this machine: moai-cowork's sync-audit workflow (`moai verify check`). Regenerating that project removes the call; keeping the workflow makes it a port (about 1,430 lines).
4. **`bundle add|remove|list` (retire here, the card text says port).** The card lists "bundle asset add/remove/list first"; this scan found no use: `~/.moai/user-assets.json` does not exist on this machine and no skill, hook or settings file calls the actions. The Rust `bundle` words must be taken off the Go list in any case.
5. **Go-generation project hooks.** 74 projects have `.claude/hooks/moai/` (70 wired in `.claude/settings.json`) and 13 have the two git hooks. `moai hook …` is already swallowed by Rust (exit 0), so no call blocks, but the Go-only duties stop running (security guardian, `harness-observe`, review gates, `chain-event`, `pre-push`, `stop-goal`, `spec-status`). Replacement per project: `go-hooks-plan|apply` for the Claude entries; the git hooks need their own step (decision 1).
6. **`profile` (retire).** Nothing calls it, but `~/.moai/claude-profiles` holds 4 named Go profile dirs and Rust `cc` has no profile option. A person typing it in a terminal is not visible to this scan.

### Not checked

Shell history, other machines, `settings.local.json` files, Go-generation projects outside `/Users/goos/MoAI` and `/Users/goos/moai`, Orca's own app bundle, `~/.unpeel/hooks/claude-hooks.sh` (absent here). Go `--help` was read for every routed word; no Go subcommand was run without `--help`.

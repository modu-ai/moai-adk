# Statusline: numbers instead of bars, weekly reset countdown, worktree moves to line 2

## Intent

2026-11-20T21:5xZ 사용자 지시(목업을 보고 고른 최종 레이아웃)예요. 목표 두 줄, 글자 단위: 줄 2 `📡 modu-ai/moai-adk, ⬇️ 0 🔀 0 | 🅱️ v2026.11.0 ↑207 +11 | 🌳 c135`(워크트리 🌳 라벨이 줄 3 끝에서 줄 2 끝으로), 줄 3 `🗂️ 105 ▶️ 24 🔃 21 ✅ 76 | 🪫 CTX 97% | 🔋 Week 21% (resets in 6d 21h)`. 줄 1은 그대로. 바꿈: (1) 막대 그래프를 없애고 `CTX <n>%`·`Week <n>%` 숫자로(콜론 없음), (2) `(⚠️ /clear)` 안내 삭제 — 사용자 예시가 CTX 97%(hard 구간)인데도 힌트가 없으므로 soft·hard 두 안내 모두 빼고 🔋→🪫 아이콘 전환(70 초과)은 유지, (3) 주간 창에 리셋 카운트다운 `(resets in <d>d <h>h)` — 영어로, `rate_limits.seven_day.resets_at`(src/statusline/input.rs:152)을 렌더 시각과 비교해 하루 이상은 `<d>d <h>h`, 하루 미만은 `<h>h <m>m`, 한 시간 미만은 `<m>m`, resets_at 이 없으면 `(resets in …)` 없이 `Week <n>%`만, (4) 워크트리 라벨은 줄 2 끝.

## Interview

- Q1: 카운트다운의 "지금"은요? → A: 렌더러가 이미 받는 `--now-unix` 시접(#2756 AC-8, `Context.now`)을 써요. Status 가 그 값을 실으면 골든은 시계와 무관하게 바이트 고정돼요.
- Q2: 리셋이 지난 뒤는요? → A: 남음이 0 이하면 `(resets in 0m)` — 창이 곧 초기화된다는 사실을 유지해요.
- Q3: 막대 그리기 코드는요? → A: CTX·Week 가 막대를 쓰지 않게 되면 `usage_bar`·`gradient_bar`·`unknown_bar` 는 미사용이 되어 삭제해요(clippy -D warnings). `theme.warn`·`alert` 필드는 공개 구조체 필드라 남겨요.
- Q4: 골든은요? → A: `statusline-claude` 세트를 골든 도구로 전부 재생성하고 diff 를 전수 리뷰해요(막대→숫자·워크트리 이동·카운트다운만 변해야 해요).
- Q5: 사용자 예시 시험은요? → A: C-203 의 예시 단위 시험을 새 두 줄로 갱신하고, 워크트리 없음·resets_at 없음 변형도 같이 고정해요.

## Non-goals

- 줄 1(태그·모델·effort·버전)의 어떤 변경도 없음.
- 리셋 시각 수집·파싱의 변경(input.rs 의 resets_at 읽기는 그대로, 이 SPEC 은 표시만).
- `usage_5h`·`git_status` 같은 숨은 옵션 이름의 제거(받기만 하고 아무것도 안 보이는 규칙 유지).
- handoff 단계 판정(segments::handoff_stage)의 삭제 — 데이터는 수집되지만 줄에는 안 보여요.

## Requirements

- REQ-1: When the worktree segment is enabled and the worktree name is not empty, line 2 shall end with the worktree label after the branch and the pull request segment.
- REQ-2 (REQ-1): IF the worktree name is empty, THEN line 2 shall end without the worktree label.
- REQ-3: Line 3 shall show the context usage as `CTX <n>%` with the battery icon that switches to 🪫 above 70, with no bar graph, no colon and no `/clear` hint.
- REQ-4: Line 3 shall show the weekly usage as `Week <n>%` with the same battery icon switch, no bar graph and no colon.
- REQ-5: When the weekly window carries a reset instant, line 3 shall append a `(resets in …)` countdown counted against the render clock, in the days-and-hours, hours-and-minutes or minutes-only form the remaining time selects (a day or more, under a day, under an hour).
- REQ-6 (REQ-5): IF the reset instant is missing, THEN line 3 shall show the weekly usage without a countdown.
- REQ-7: The countdown shall take the reset instant from `rate_limits.seven_day.resets_at` and the render clock from the existing `--now-unix` seam.
- REQ-8: The `statusline-claude` goldens shall be regenerated by the golden tool and reviewed as one whole diff.
- REQ-9: The unit tests shall pin the user's example two lines byte for byte for the example status, its no-worktree variant and its no-resets_at variant.

  verify: `cargo test --locked --offline --lib statusline`
- AC-2 (REQ-3): CTX 97% 예시가 `🪫 CTX 97%` 로 나오고 막대·콜론·힌트가 없어요.
  verify: `cargo test --locked --offline --lib statusline`
- AC-3 (REQ-4, REQ-5, REQ-6, REQ-7): resets_at 이 6일 21시간 뒤면 `🔋 Week 21% (resets in 6d 21h)`, 없으면 `🔋 Week 21%`, 경계(86400·3600초) 단위 시험이 d/h/m 형태를 고정해요.
  verify: `cargo test --locked --offline --lib statusline`
- AC-4 (REQ-8): 골든 도구 재생성 뒤 전체 `--check` 가 통과하고, 바뀐 골든의 diff 전수 리뷰에서 막대→숫자·워크트리 이동·카운트다운 외 변화가 없어요.
  verify: `python3 -I tools/statusline_golden.py --check`

## Decisions

- D-1: `Status` 에 `now` 필드를 더하고 수집기가 `Context.now`(= `--now-unix` 시접)로 채워요 — 새 시접 없이 결정적 골든을 유지해요.
- D-2: 카운트다운은 `segments::reset_countdown(resets_at, now)` 순수 함수로: 남음 ≥ 86400 `(resets in <d>d <h>h)`, ≥ 3600 `(resets in <h>h <m>m)`, 0 초과 `(resets in <m>m)`, 0 이하 `(resets in 0m)`(내림, 경계 단위 시험).
- D-3: `/clear` 안내는 soft `(⚠️ /clear)`·hard `(🛑/clear!)` 둘 다 줄에서 빠져요 — 사용자 예시(CTX 97% = hard 구간)에 힌트가 없기 때문이고, handoff 데이터 수집은 그대로예요.
- D-4: 막대가 레이아웃에서 빠지므로 `usage_bar`·`gradient_bar`·`unknown_bar` 와 `BAR_WIDTH` 를 삭제해요(미사용 코드 — clippy -D warnings). `Theme` 의 `warn`·`alert` 필드는 공개 필드라 그대로 두고 `HandoffStage` 임포트는 빼요.
- D-5: 워크트리 라벨은 `git_line` 끝(브랜치·PR 다음)으로 옮기고 `bars_line` 에서는 빼요. 문서(rust-product-path 항목)와 render 주석이 새 자리를 말해요.

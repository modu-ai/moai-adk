## §D The five required SPEC decisions (card-mandated, each resolved here)

**D1. Emission target layout — build-time committed artifacts under
`templates/.agents/skills/`.**
The published skills are generated at emit time into
`internal/template/templates/.agents/skills/moai-<command>/SKILL.md` as committed real
files, golden-checked (D4), and distributed by the existing embed+deploy machinery (R-010).
Rejected alternative — deploy-time generation (like the mirror): it would leave no
committed artifact for the drift check to judge, and the mirror's deploy-time shape exists
only because symlinks cannot be embedded; the published skills have no such constraint.
Coexistence with the 34-skill mirror (R-006): the mirror writes only entries named after
canonical `.claude/skills/` directories; the emitter writes only `moai-<command>` entries;
the two name sets are disjoint (measured 0/16 collisions), and both live under the same
`.agents/skills/` root so codex scans one directory for all 50 skills.

**D2. Skill identity — `moai-<command>` derivation; refuse-and-report collision policy.**
Bare command names (`plan`, `run`, …) are too generic for the `$` sigil namespace and would
collide with user skills more readily; the `moai-` prefix keeps the published set visibly
one family next to the 34 `moai*` skills in `/skills` browse. Collision policy:
refuse-and-report (R-004, fail-closed, agentemit precedent) — a suffix policy would silently
shadow, and the overwriting hazard the card names (mirror overwriting a collided skill) is
exactly what refusal prevents. Measured baseline: 0/16 collisions today; the guard exists
for future commands.

**D3. Body provenance — verbatim publish; t497 owns repair.**
The body is the source bytes after the frontmatter delimiter, untransformed (R-005). The
published body's known defect — it instructs a Claude-only `Skill("moai")` call — is
RECORDED as a boundary flag in the emitter's per-skill report (build log / test output),
not repaired. This keeps this SPEC's diff purely additive and makes t497's repair a
body-layer change that automatically propagates through regeneration.

**D4. Freshness/validation — the agents-emit pattern, mirrored.**
- Golden test in the emitter package, dual-mode: regeneration verb sets an env switch
  (`AGENTEMIT_UPDATE`-style) and rewrites the committed artifacts; unset, it compares and
  fails on drift.
- Make targets: `<emit>` (regeneration) + `<emit>-check` (read-only drift check) +
  `<emit>-check` wired as a `build` prerequisite in the same position as
  `agents-emit-check` (names chosen at run-phase; behavior per R-007/R-008).
- CI: the existing `template-neutrality-check.yaml` path filter
  (`internal/template/templates/**`) already covers the emitted subtree; no new workflow
  file. The drift check runs in the build prerequisite locally and in the standard build
  job in CI.

**D5. Documentation surface — one section pointer, not a doctrine.**
A short section in `CLAUDE.local.md` §2 area (or the adjacent local-dev doc) pointing at
the emitter: what it publishes, the regeneration verb, and the t497 boundary. No new
doctrine file, no docs-site changes (docs-site is a separate publication path and out of
scope).

## §G Anti-Patterns (this SPEC's named traps)

- **Repairing the body "while we're here"** — the `Use Skill("moai")` line is broken in
  codex; fixing it is t497's whole job. Publish verbatim; flag; move on.
- **Writing `[[skills.config]]`** — registration is by path convention; the config table is
  disable-only (t494 §4).
- **Suffixing a collision** — refuse instead (R-004); a `moai-plan-2` silently shadows
  nothing and explains nothing.
- **Embedding symlinks** — not applicable here (real files), but do not "simplify" the
  mirror coexistence test away: the two mechanisms share one directory root and the test is
  the only guard on that seam.
- **Locale-conditional descriptions leaking** — the emitted description must be the plain
  English branch; an emitted `{{if eq .ConversationLanguage ...}}` is a defect AC-004
  catches.

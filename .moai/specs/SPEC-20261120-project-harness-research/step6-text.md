When web search is unavailable, propose from the detected facts alone and say that no source was read. Propose only what the stack and the sources justify: there is no fixed count of project agents or project skills (`generation-plan` takes up to sixteen of each in one request). Each proposal states its purpose, the tools it needs (agent) or the trigger (skill), its scope, the reason it is proposed and its sources. Keep every proposal generic and portable: no internal tool of this project, no secret, no absolute home path.

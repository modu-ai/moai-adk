# 자모 무결성 가이드 — GLM 채널 한국어 오염 검출·복원

> 카드 t1336. 대상: 레인(팩토리·칸반) 세션. 판정 근거: `.moai/reports/t1336/characterization.md`.

## 무엇이 문제인가

모델 백엔드 출력 채널(GLM 레인에서 관측)이 한국어 단어의 자모 슬롯(초성·중성·종성)을 가끔 갈아엎어 내보낸다. 오염 음절은 **유효한 조합형 음절**이라 NFC/NFD 정규화로는 검출도 수리도 안 된다. 겉보기에 정상형과 구별이 안 되는 변형(`스`↔`슠`)도 있다. 같은 채널로 재타이핑하면 수리가 아니라 **재오염**이다 — 사람 손이 아니라 기계 검증으로만 수리한다.

## 카드를 닫기 전 — 보고서·판정문에 이 한 줄을 돌려라

```bash
python3 scripts/jamo_integrity.py check <내가 쓴 보고서.md> <판정문.md>
```

- 출력 `OK` → 끝.
- 플래그가 나오면 아래 복원 절차. 종료 코드는 발견 시 1이라 게이트에 물릴 수 있다.

## 오염이 걸리면 — 복원 절차

```bash
# 1) 항상 dry-run 먼저 — 뭐가 뭐로 바뀌는지 사람이 읽는다
python3 scripts/jamo_integrity.py restore --dry-run <파일...>

# 2) dry-run 목록을 검토했고 짧은 단어의 대체가 틀리지 않았다고 확인하면 적용
python3 scripts/jamo_integrity.py restore --apply <파일...>
```

- 자동 수리는 **거리 1 후보가 유일할 때만** 적용된다(복합어로 파싱되는 단어는 가드에서 제외). 나머지는 `ambiguous`로 사람 검토 대상으로 남는다.
- **dry-run 검토 없이 `--apply` 하지 마라.** 실측상 짧은 단어는 오수리가 있다: `숴환→소환`(본래 순환), `큜→큐`(본래 및)가 d=1 유일 후보로 승격돼 틀린 사례가 t1336 재료에서 관측됐다.
- 펜스 코드 블록(``` ```)과 인라인 코드는 절대 재작성하지 않는다.
- 애매한 항목은 본래형을 문맥으로 판단해 손으로 고치되, 고친 뒤 반드시 `check`로 재검증한다.

## 하지 말 것

- **오염 채널로 재타이핑해서 수리했다고 하지 마라.** 증거는 재출력이 아니라 `check` 통과다.
- `unicodedata` NFC/NFD 정규화로 수리하려 하지 마라 — 이 오염 클래스는 정규화 불변이다(실측: 재료 파일 NFC 재인코딩 바이트 동일).
- 사용자 프로젝트에 템플릿 미러를 만들지 마라 — `scripts/` 는 이 저장소 전용 도구다.

## 근원지와 처분

근원은 **모델 백엔드 출력 토큰 스트림**이다. 레인이 고칠 대상이 아니므로 `/moai:feedback` 으로 운영자 보고 항목을 남기고, 레인의 완결 범위는 검출·복원·이 가이드의 예방 3가지다. 대량 오염이 관측되면 그 세션의 한국어 출력을 전부 `check`로 훑고, 채널 자체 의심 시 판정문에 채널명을 명시한다.

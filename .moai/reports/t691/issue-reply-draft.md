# #1682 회신 초안 (카드 t691)

> 리드 게시용 초안 — 2026-09-13 작성. 게시 전 리드가 확인합니다.

---

안녕하세요, 보고해 주셔서 감사합니다. 확인해 보니 증상은 Claude Code의 교차 세션 메시징 가용성 결정 방식과 moai 런처의 설정 태도가 겹친 지점에서 나옵니다. 조사 내용과 저희 판단을 정리해 드립니다.

## 1. 기제 — 공유 플래그 슬롯

Claude Code는 피어 메시징(ListAgents/SendMessage) 가용성을 기기 전역 공유 플래그 슬롯, 즉 config dir의 `.claude.json` 안 `cachedGrowthBookFeatures.tengu_harbor_kite` 값으로 판단합니다. 이 슬롯은 마지막에 쓴 세션이 이기는(last-writer-wins) 기기 공유 값이고, `ANTHROPIC_BASE_URL` 호스트가 `api.anthropic.com`인 세션만 슬롯을 읽어 와 기록합니다. 그래서 z.ai(GLM)나 로컬 게이트웨이 같은 서드파티 백엔드 세션은 슬롯을 쓰지 않는데, 기기의 슬롯 값이 false로 남아 있으면 그 클래스 세션에서 메시징 도구가 사라집니다.

## 2. 새로 확인한 행동 재현

이번에 슬롯 값 하나만 다른 두 세션을 나란히 돌려 행동 차이를 직접 확인했습니다 (동일 기기·바이너리·환경, glm-5.3-flash / z.ai, 격리된 `CLAUDE_CONFIG_DIR` 프로파일 — 실제 `~/.claude.json`은 건드리지 않았습니다):

| 슬롯 `tengu_harbor_kite` | ListAgents 도구 | 관측된 응답 |
|---|---|---|
| true | 존재 | "peer messaging itself is available" |
| false | 툴셋에서 완전 제거 | "There is no tool named ListAgents in my available toolset" |

즉 소켓이 없는 수준이 아니라, 도구 자체가 툴셋에서 빠집니다. 이전 조사(카드 t400)에서 소켓 존재를 쟀다면, 이번 재현은 행동 차이까지 닫은 것입니다.

## 3. moai가 기본으로 주입하지 않는 이유

런처(`moai cc` / `moai glm` / `moai cg`)가 세션에 `CLAUDE_CODE_HARBOR_KITE=1`을 넣어주면 증상은 사라집니다. 다만 저희는 넣지 않기로 판정했습니다. 근거는 다음 네 가지입니다.

- **사설 플래그입니다.** 이 env는 문서화되지 않은 내부 플래그라 이름과 의미가 예고 없이 바뀔 수 있습니다. 런처에 기본값으로 박아 넣으면 플래그가 나중에 메시징 외의 다른 동작을 게이트하기 시작했을 때 세션이 조용히 달라집니다.
- **사용자의 기기 전역 설정을 덮어씁니다.** 슬롯은 사용자 환경이 협상해 놓은 상태입니다. false가 된 이유가 무엇이든 — 비필수 트래픽 제한 계열 플래그(`DISABLE_TELEMETRY` 등)로 인한 경우도 있을 수 있습니다 — 런처가 `=1`을 강제하면 그 의사 위에 moai의 기본값을 얹게 됩니다. 다만 여기서 측정된 범위는 "이 env가 슬롯 값보다 먼저 읽혀, 슬롯이 false일 채널을 켠다"까지이고, 플래그 평가 자체가 꺼진 환경에서 이 env가 어떻게 동작하는지는 검증하지 않았습니다.
- **GLM만의 문제가 아닙니다.** 로컬 게이트웨이(GPT) 세션도 같은 슬롯 비기록자입니다. GLM에만 넣으면 불일치가 되고, 전부에 넣으면 위의 설정 덮어쓰기가 넓어질 뿐입니다.
- **피해 범위가 유계입니다.** moai의 실제 작업 위임 채널은 디스크의 큐이고, 메시징은 그 위의 편의성 nudge 층입니다. 없어도 조용히 진행되고, 1st-party 세션이 다음에 슬롯을 기록하면 저절로 복구됩니다.

## 4. 지금 당장 필요하신 경우 — 수동 탈출구

해당 세션을 띄우기 전에 다음처럼 env를 지정하시면 슬롯 값과 무관하게 메시징이 켜집니다 (env가 슬롯보다 먼저 읽힙니다):

```bash
export CLAUDE_CODE_HARBOR_KITE=1
moai cc -w <name>
```

세션별이 아니라 항상 켜두길 원하시면 셸 프로파일에 넣으셔도 됩니다 — 이건 사용자분의 선택이고, moai가 대신 정해 주는 영역이 아니라고 보았습니다.

## 5. 후속 후보 — doctor 검사

강제 대신 가시성을 높이는 방향으로, `moai doctor`에 "서드파티 백엔드 세션인데 슬롯이 false다" 조합을 감지해 위 탈출구를 안내하는 검사를 후보로 검토 중입니다. 별도 카드로 접수될 예정입니다.

<h1 align="center">MoAI-ADK</h1>
<p align="center"><strong>토크노믹스를 목표로 하는 Agentic Development Kit</strong></p>
(배지 · 4-locale 링크 · 공식 문서/책/Discord — 기존 유지)

> **"바이브 코딩의 목적은 빠른 생산성이 아니라 코드 품질이다."**

MoAI-ADK(Agentic Development Kit)는 **토크노믹스(Token Economics)를 목표로 하는
에이전틱 개발 키트**입니다. 같은 품질의 코드를 더 적은 토큰으로, 같은 토큰으로 더 높은
품질을 — 모델 선택·추론 깊이·컨텍스트 사용량을 시스템이 관리합니다.

Go로 작성된 단일 바이너리. 의존성 없이 macOS · Linux · Windows에서 바로 실행됩니다.

## 왜 토크노믹스인가

토큰 단가는 계속 내려가지만, 에이전틱 개발의 토큰 사용량은 그보다 빠르게 늘어납니다.
에이전트가 여러 개 돌고, 컨텍스트가 길어지고, 추론이 깊어질수록 **비용은 모델 가격이
아니라 토큰 운용 방식**이 결정합니다.

MoAI-ADK의 답은 세 가지입니다.
1. **작업마다 맞는 모델·추론 깊이를 배정한다** — 계획은 깊게, 구현은 싸게, 검증은 독립적으로.
2. **컨텍스트를 다이어트한다** — 항시 로드 지침 최소화, 프롬프트 캐시 적중률 측정.
3. **예산을 시스템이 지킨다** — 토큰 사용 추적, 임계 초과 전 우아한 중단.

## 핵심 가치 — 세 가지 기둥

### 🪙 토크노믹스 (Token Economics)
No-Haiku 3-계층 모델 정책(max/medium/low), 요금제 인지 티어 프로파일(API vs 구독),
Claude×GLM 하이브리드(CG 모드, 60-70% 절감), Token Circuit Breaker.

### 🔁 재귀적 자가 학습 (Recursive Self-Learning)
Routing Observation Ledger가 라우팅 결정을 기록하고, Curator가 개선 제안을 만들며,
4-계층 학습 사다리(관찰→휴리스틱→규칙→자동 업데이트)가 사용자 승인 게이트 아래에서
하네스를 업그레이드합니다.

### 🤖 에이전틱 하네스 (Agentic Harness)
코드를 직접 쓰는 대신, 에이전트가 잘 일할 환경을 설계합니다. 10개 에이전트 카탈로그,
SPEC 3-phase(plan→run→sync), TRUST 5 품질 게이트, 자연어 Harness v4 Builder.

## 🪙 토크노믹스 심화
### No-Haiku 3-계층 모델 정책
| 정책 | 대상 | 특징 |
| max | Max $200/월 | 최고 품질 — 계획·감사에 Opus/Fable |
| medium | Max $100/월 | 품질·비용 균형 |
| low | Plus $20/월 | Opus 미포함, Sonnet 중심 |
`--model-policy` 플래그 + HARD 린트가 정책 위반 차단.

### 요금제 인지 티어 프로파일 (plan_type)
API 종량제와 구독 요금제는 최적 배분이 다르다 — 요금제별 Tier×Phase 모델/effort
매트릭스 분리 적용 + GLM 백엔드 effort 오버레이.

### Claude × GLM 하이브리드 (CG 모드)
`moai cg` — Claude 리더 + GLM 워커. 구현 중심 작업 **60-70% 비용 절감**.
glm-5.2[1m] 단일 모델(1M 컨텍스트, 입력 $2 / 출력 $8), z.ai 암시적 캐싱.

### Token Circuit Breaker
에이전트별 토큰 추적 → 경고 → 임계 초과 시 우아한 중단(상태 저장 + 핸드오프).
자동 /clear는 절대 하지 않음.

### 컨텍스트 다이어트 + 프롬프트 캐시
항시 로드 예산 가드(CLAUDE.md 405→319줄), 규칙 path-scoping,
statusline cache_hit 세그먼트, 검증 출력 파일-리다이렉트.

## 🔁 재귀적 자가 학습
### 자가 진화 하네스
루프 실행 → 관찰 축적(Routing Ledger) → 패턴 학습(Curator) → 지침 진화(승인 게이트)
- 4-계층 학습 사다리: 관찰(≥1) → 휴리스틱(≥3) → 규칙(≥5) → 자동 업데이트(≥10, 승인 필수)
- 5-Layer 안전 파이프라인 + 스냅샷/롤백
- moai harness status|apply|rollback|disable|list|edit|remove|doctor

### /moai goal — 조건 선언형 에이전틱 루프
    /moai goal "go test ./... exits 0; 모든 AC가 PASS로 기록"
조건 충족 또는 턴 한도(기본 30)까지 세션이 스스로 일합니다.
/moai loop는 goal 엔진 위의 프리셋 — 진단 이슈 큐를 비울 때까지 반복 수정.

### 세션 핸드오프 auto-resume
컨텍스트 임계(1M 모델 50% / 200K 모델 90%)에서 붙여넣기 한 번으로 다음 세션 연속.

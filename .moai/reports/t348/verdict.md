# t348 verdict — AC counter grammar widened + native prefix declaration

Card: t348 (G2a, lane-9, Tier M) · Branch: WT-ac-prefix-grammar · Base: develop `131daa290` (absorbed via fast-forward)

## Claim

The B12 AC-count convention no longer silently skips existing citation files: (1) the counter grammar accepts a trailing lowercase sub-letter (`[a-z]?`) so sub-lettered identifiers count whole instead of folding into their numeric prefixes; (2) the convention carries a NATIVE PREFIX DECLARATION (`<!-- moai-ac-prefix: CR -->` on its own line, comma-separated letter-digit tokens REPLACING the default `AC` for that file) so a counted file declares its own grammar instead of the grammar being regex-frozen. Both changes landed byte-identically in the agent-file clause carriers (local + template mirror) and propagate mechanically through the repository-local verifier that EXTRACTS the counter from those carriers.

## Evidence

1. **The premise, measured at corpus scale**: sweeping all `.moai/specs/*/acceptance.md` for AC-shaped identifiers found **1,002 distinct identifier forms** the counter's regex (`AC-([A-Z0-9]+-)*[0-9]+`) cannot see — every one of them the trailing-sub-letter family (`AC-003a`, `AC-013i`, `AC-GF-Nx` shapes; 44+ SPECs affected). No acceptance file uses a non-AC criterion prefix (heading sweep → only Scenario/section headings), so the declaration has zero current consumers — it exists to un-freeze the grammar, stated honestly.
2. **RED observed twice**: (a) the Go harness with the two new fixtures against the unmodified clause — `subletters.md: live count = 4, want 3` / `prefixdecl.md: live count = 0, want 1`, both FAIL; (b) the old counter re-extracted from git HEAD and run directly — `subletters.md → live=4 excluded=0` (folding `AC-003`/`AC-003a` into one id, misattributing excluded states), `prefixdecl.md → live=0` (the vacuous zero the convention itself names a RED flag). Verbatim: `.moai/reports/t348/red-old-counter.log`.
3. **The fix**: counter block rewritten in BOTH clause carriers — `BEGIN { prefixes = "AC" }` default, first `^<!-- *moai-ac-prefix:` line parsed once, dynamic pattern `"(" prefixes ")-([A-Z0-9]+-)*[0-9]+[a-z]?"`, unchanged three-state/halt semantics; prose gains the sub-letter rule (a sub-letter is its own criterion, never folded) and the **Native prefix declaration** paragraph (replaces, extends nothing; cross-namespace citations stay `[REF]`; a first declaration wins).
4. **GREEN observed**: `make agents-emit` EXIT=0 (codex TOML carrier regenerated); all AC-family tests PASS — `TestACCounterFixtureCorpus` (both new hand-derived cases + the three originals), carrier-extraction byte-parity, partial-marking halt, no-real-SPEC-ID, codex-carrier reach. 9 PASS, exit 0: `.moai/reports/t348/green-test-run.log`.
5. **Corpus baseline regenerated** with the new counter via the committed t338 recipe (`.moai/reports/t338/run-scratch/gen-baseline.sh`): `.moai/reports/t338/ac-count-baseline.txt` 248 lines changed (147+/101-). Sample deltas observed pre-regeneration — SPEC-AUDIT-GATE-INTEGRITY-001 14→25, SPEC-AUDIT-SNAPSHOT-001 4→7, SPEC-AGENT-PROGRESS-PUSH-001 37→50 — the old counter had been undercounting whole SPECs by double-digit percentages; `TestACCounterFullCorpusMatchesBaseline` now PASSes against the regenerated snapshot.
6. `make build` EXIT=0.

## Gaps (explicitly NOT observed)

- The declaration syntax has zero real consumers today — measured; it is exercised by the fixture only. A future SPEC with a non-AC criterion namespace will be its first user.
- Halting files in the corpus were not separately re-examined: the regenerated baseline carries HALT lines through the same recipe; any pre-existing HALT state is unchanged by this card (the grammar change does not resolve an ambiguous identifier).
- CHANGELOG entries already emitted under the old undercount were NOT retroactively audited — the count claims in historical CHANGELOG lines for sub-letter SPECs understate their AC counts; correcting published entries is outside a rules card's scope (would need a docs/CHANGELOG owner).
- Full `go test ./...` not run (lane-local scope: `./internal/spec/` + `make build`); CI owns the full-suite verdict.

## Residual-risk

- The dynamic pattern is built from the declared prefix list without validation; a malformed declaration (e.g., an unbalanced regex metacharacter) makes awk fail loudly at run time rather than silently miscounting — fail-loud accepted over adding validation code for zero current consumers.
- Files that DECLARED nothing but carry sub-letter citations of OTHER SPECs' criteria get those counted now (they were skipped before) — the same counted-reference exposure the convention already carries for plain cross-SPEC AC citations; the [REF] machinery is the remedy, unchanged.

### N5. **[신규]** 뮤턴트가 가드의 **절반만** 증명한다 — 증명되지 않은 쪽이 「제자리 수정」을 잡는 프로브다
`acceptance.md:16-25` · `plan.md:25-36` — Severity: **major** — Class: **blocking**

AC-CGM-001 의 가드는 프로브가 **둘**이다.

1. 엔트리 목록 — `ls -la ~/.codex | awk 'NR>1{print $NF}' | sort`
2. mtime — `stat -f '%N %m' ~/.codex/* ~/.codex/.[!.]* 2>/dev/null | sort`

`Then` 은 「**양쪽 모두** 무출력」을 요구하는데, 뮤턴트는 **1번만** 친다. **내가 `/tmp` 에서 재현**: `D=$(mktemp -d); touch "$D/a" "$D/b"` → 셀렉터 → `touch "$D/.mutant"` → `diff` → **`2a3 > .mutant`, rc=1**. 저자 인용값과 일치하고, **동일 셀렉터**를 쓰므로 엔트리 프로브의 물성은 진짜로 증명된다(질문 3 의 앞 절반은 통과다).

`plan.md:29` D-2 는 「부재를 PASS 로 삼는 **모든** 검사는 대조군을 짝으로 갖는다」이다. mtime 프로브는 부재(무출력)를 PASS 로 삼으면서 대조군이 없다 — **이 카드 자신의 D-2 위반**이다.

**수리(비용 0)**: 같은 격리 디렉터리에서 두 번째 뮤턴트 한 줄. `touch "$D/a"` 로 기존 파일 mtime 만 올린 뒤 mtime 셀렉터 diff 가 red 로 서는지 본다 — 엔트리 diff 는 무출력인데 mtime diff 는 red 인 것이 확인되면, 두 프로브가 서로 다른 사건을 잡는다는 것까지 함께 증명된다.

(a) **`grep -c -- '--force' .moai/reports/t533/measure.sh`** 를 「실제로 `0` 을 찍는 자리」로 분류했으나, `measure.sh` 는 **아직 존재하지 않는다**(M3 에서 run 단계에 만든다). 오늘 실측: **`rc=2 len=0 out=[]`** — 아무것도 찍지 않는다. 게다가 이것은 표의 2분법(깨진 계기 rc=1 무출력 / 정상 계기 rc=1 `0`)이 담지 못하는 **제3의 경우**(코퍼스 부재, rc=2)다. 표가 「재확인된 상태」를 선언하므로, 재확인할 수 없는 행이 확인된 것으로 실린 셈이다.

(b) **`LC_ALL=C grep -ac` 3종**을 통째로 「0 을 찍는 자리」에 넣었는데, 그 셋 중 `moai` 는 **`1071`** 을 찍는다(`rc=0 len=4`). 「수를 찍는다」는 참이고 「`0` 을 찍는다」는 거짓이다.

**수리**: (a) 행을 「run 산출 후 측정 대상 — 현재는 코퍼스 부재로 `rc=2` 무출력」으로 옮기고 제3 경우를 표에 추가. (b) 「수를 찍는 자리(값은 각각 1071 / 0 / 0)」로 문구 수정.

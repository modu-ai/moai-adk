## 차단 5건 — 전부 직접 확인함, 5건 다 유효

### F1 (High) — `tokens` 의 임의 키가 인증으로 통과

`map[string]nonEmptyString` 로 받아 **키를 보지 않고** 비지 않은 값을 센다. 감사 실측:

```
{"irrelevant":"x"} => count=1 err=<nil>     ← 무관한 메타데이터가 ChatGPT 인증이 된다
false / 0 / [] / { } => count=0             ← 이 넷은 정상 거부
```

JSON 원시 타입 문제는 닫혔지만 **의미 수준 검증** 이 없다. AC-CL-008 표에도 `tokens: false` · `tokens: 0` · `tokens: {"irrelevant":"x"}` 행이 없다. REQ-CL-008 의 "그 모드가 함의하는 자격 재료" 를 만족하지 못한다.

→ 필요한 것: ChatGPT 모드가 인정하는 **키 집합** 정의 + 무관 키·계정 메타데이터만 있는 경우의 음성 케이스.

### F2 (High) — 상태 × 동사 교차곱 미커버

AC-CL-015 는 배선 5종을 **`cli` 로만** 돌린다. 그런데 REQ-CL-015 는 launch 동사 **둘 다**, REQ-CL-006 은 **리드아웃** 에 적용된다. 그래서 다음이 전부 통과한다:

- `cli` 는 제대로 막으면서 `app` 은 미배선으로 기동
- `status` 가 빈 디렉터리·한쪽 파일만 있는 상태를 정상으로 보고
- 미배선 4종 중 한 종에서만 수락/거절 동작을 시험

→ 필요한 것: 5상태 × {`status`, `cli`, `app`} 표 시험, launch 두 동사 각각 수락/거절 · 생성기 argv·횟수 · exec 횟수 · 트리 보존.

### F3 (High) — 로컬 지시 파일 도달성·멱등이 여전히 헐거움

`@AGENTS.md` 줄 형태와 "둘 다 있는데 미연결" fixture 는 들어갔다. 그러나 `CLAUDE.local.md` 쪽은:

- **실행되는 import 형태를 정하지 않았다** — 내 AC 는 "가리키는 줄" 이라고만 썼다
- 그래서 **불활성 산문 한 줄** 로도 줄 수 판정을 만족시킨다
- 2회 실행 바이트 비교 문단에 **local-present fixture 가 명시적으로 포함돼 있지 않다** — 2회차에 로컬 링크만 중복돼도 통과한다

### F4 (Medium) — `probe.sh` 가 선행 조건 실패에 여전히 안 멈춤

직접 확인했다. `set -uo pipefail` 만 있고 **`set -e` 가 없다**. 그리고 `run()` 이:

```bash
run() { echo "\$ $1"; eval "$1"; echo "rc=$?"; echo; }
```

내부 rc 를 **출력만** 하고 반환값은 마지막 `echo` 의 것(항상 0)이다. 감사 실측: `cmd=false / inner_rc=1 / continued=yes / wrapper_script_rc=0`. `mktemp -d` 도 검사하지 않아 실패 시 경로가 `/moai`·`/doctor.json` 이 된다.

내가 앞 라운드에서 넣은 `[ -x "$MOAI" ] || fail` 두 줄은 **그 두 지점만** 막았고, 나머지 모든 단계는 여전히 실패해도 스크립트가 초록으로 끝난다. **"선행 조건 실패 시 중단한다" 는 내 주석은 과장이었다.**

### F5 (Medium) — 전사본이 주장된 기준선이 아님 (내가 만든 불일치)

전부 실측 확인:

원인은 단순하다 — 3건을 고치며 probe 를 재실행했는데 **그 결과를 인용하는 문서들의 숫자를 따라 고치지 않았다.** 전사본 방식으로 바꾼 이유가 바로 이 종류의 드리프트를 없애는 것이었는데, 문서 쪽에 남은 수치가 다시 드리프트를 만들었다.

부분 반론 1건: `measurement.md:41` 의 MCP 결과가 전사본에 없다는 지적은 맞지만, 그 문단은 "**전사본에 없다** — 셸에서 재실행할 수 없으므로 rc 가 없다" 고 명시하고 있다. 숨긴 것이 아니라 공시한 예외다. 다만 "별도 전사본으로 분리하라" 는 권고는 타당하다.

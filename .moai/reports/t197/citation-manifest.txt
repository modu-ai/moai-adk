# t197 citation manifest — the binding a citation gate can actually check.
#
# One row per (citing file, transcript range). Fields separated by `~`:
#
#   citing_file ~ transcript_range ~ claim_regex ~ support_regex
#
#   claim_regex    must match the citing line — selects which row governs a
#                  citation when one line cites several ranges.
#   support_regex  must match INSIDE the cited transcript range — this is the
#                  check that catches a citation whose range is valid but whose
#                  content does not show the claim (the iteration-7 F1 shape).
#
# What this manifest does NOT prove: that the Korean prose around the citation
# is a fair reading of the matched line. It proves the range exists, is bound to
# a claim, and contains the evidence token that claim rests on. Semantics stay a
# reviewer's job — stating that limit is the point, since the previous sweep
# claimed more than it checked.
#
# A citation with no row here FAILS the gate. A row here whose (file,range) is
# no longer cited FAILS the gate as stale. Both directions, on purpose.

## 5. Gaps

- Anchors were not repaired, by card scope (prefix only). All 14 SK-03 links still carry
  `#subcommand-classification`. The heading at `spec-workflow.md:77` is
  `## Subcommand Classification (Pipeline vs Multi-Agent)`, whose slug is
  `subcommand-classification-pipeline-vs-multi-agent`, so the checker reports `ANCHOR=MISSING` on
  all 14. The files resolve, but an in-page jump does not. The sibling `run/context-loading.md:86`
  already uses the full slug (`ANCHOR=OK`).
- The checker resolves `.claude/...` link targets against the tree root, which is the
  repository's root-relative convention. A markdown renderer resolves them against the file's own
  directory instead. So the eleven carried-along testing links are OK under the convention but
  would not resolve in a plain renderer. This was not measured against any renderer.
- Anchors on non-`spec-workflow` links were not checked, because those links carry no fragment.
- `make build`, `make commands-emit-check` (standalone), `golangci-lint`, and `internal/cli` tests
  were not run (the card doesn't require them, and no Go code changed).
- The rendered deploy output of these files in a user project (`moai init` / `moai update`) was
  not observed. By instruction, neither command was run.
- No CI run on this head.

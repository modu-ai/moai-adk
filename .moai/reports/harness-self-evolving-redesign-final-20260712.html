Loop 1 — 반추 (세션 경계 + 수동 evolve)

  • 패턴 키 = request_class + subcommand + mode + outcome. 집계 시 negative evidence 레지스트리와 대조(A7) — 기각 이력이 있는 키는 신규 증거 요구량이 상향된 상태로만 재부상.
  • 집계 결과는 auto-memory에 임시 저장(Tier 1-2). 실패 패턴은 lessons-inbox에도 적재(약점 채굴 입력).
  • GLM 세션 궤적은 model_class로 가중 차등 — 관찰은 수용, 승격 제안 생성은 Opus/Fable 한정.

Loop 2 — 승격 (Self-Harness 6단계 정렬)

  • 실패 수집(ledger) → 근본원인(반추) → 편집 허용 영역만(3-Zone) → held-out(L2 Canary: shadow 적용 + doctor + 회귀 게이트) → 회귀 검사 → 채택/기각 — 카드 8의 6단계와 1:1.
  • 채택: 스냅샷 → 적용 → lineage. 기각/롤백: negative evidence 등재 + 동일 키 쿨다운(A7) — "실패한 수정도 기록"의 기계적 구현.
  • 모든 CLAUDE.md/local.md 쓰기는 L5 AskUserQuestion 승인 필수 — 예외 경로 없음.

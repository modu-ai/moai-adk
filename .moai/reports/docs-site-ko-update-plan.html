실행 요약 (Executive Summary)

새 10-섹션 README.ko.md 도입에 맞춰 docs-site/content/ko 124페이지를 전수 조사한 결과, 6건의 문서 내 모순, 8개의 신규 페이지 부재, 30페이지 분량의 claude-code/ 업스트림 섹션 de-prioritization 과제가 확인됐다.

핵심 발견 (Headline findings):

  • 문서 내 모순 6건은 README 병합 전 또는 병행 단계에서 반드시 수정해야 한다 (P0).
  • 새 README는 8개 신규 docs-site 페이지를 암시하지만 현재 존재하지 않는다 (§c).
  • 30페이지 claude-code/ 섹션은 유일한 대규모 업스트림 파생 영역 — 삭제가 아니라 "배경 참조"로 재구성한다 (§d).
  • 본문 이모지 위반은 3개 페이지에 국한되며 기계적 수정으로 해결된다 (P0).
  • changelog/_index.md는 README 배지가 v3.0.2를 표시함에도 불구하고 빈 skeleton 상태다 (P0).
Methodology 모든 페이지를 새 10-섹션 README와 매핑. 우선순위 키 — P0 정확성/모순/README 블로커 · P1 구조 정합 + calque/i18n/패리티 + gap-filling · P2 폴리시/보강/de-prioritization. 액션 키 — keep / rewrite / merge / split / new / move / delete.

Claim

이번 단계에서 native 요청·응답 필드의 실제 shape를 반영하고, 고정 GPT 구독 endpoint의 stream 계약을 맞추며, 변경 영역의 회귀 시험을 보강했사옵니다.

  • Claude Code 2.1.268의 thinking: {"type":"adaptive","display":"omitted"}를 검증하고 GPT wire에서는 presentation-only display를 생략하옵니다.
  • defer_loading: true인 도구는 입력 검증 후 초기 Responses 도구 목록에서 제외하옵니다. 후속 tool_reference 로딩은 아직 지원하지 않사옵니다.
  • AuthPKCE 고정 구독 경로에서는 max_output_tokens를 보내지 않으며, client의 비스트림 요청은 upstream에만 stream:true를 강제한 뒤 엄격한 SSE를 Messages JSON으로 모으옵니다.
  • Responses 출력 message의 phase는 commentary, final_answer, null만 수용하옵니다.
  • Responses reasoning output item의 encrypted opaque 보존·receipt 연결은 활성화하지 않았사오니, 실제 gpt-5.6-sol 정상 답변이나 resume 호환성 PASS를 주장하지 않사옵니다.

Gaps

현재의 핵심 차단: live 구독 응답에서 reasoning의 encrypted_content를 Messages의 redacted_thinking와 Responses 후속 input·receipt로 안전하게 왕복시키는 계약이 아직 활성화되지 않았사옵니다. 그러므로 “GPT가 정상 답변했다”는 판정은 내리지 않았사옵니다.
  • tool_reference에 의한 deferred tool 후속 로딩은 미지원이옵니다.
  • 구독 non-stream은 endpoint의 native non-stream 응답이 아니라 upstream SSE를 수집하는 어댑터 경로이옵니다. 서버 출력 정책과 MoAI byte·cancel·deadline 한도는 별도 계약이옵니다.
  • Windows 권한·잠금·flush·동일 볼륨 원자 교체·강제 종료 복구는 GitHub Actions Windows runner에서 실행하고 artifact/run ID를 남겨야 하옵니다.
  • Claude OAuth, GPT PKCE 실제 추론, tool 왕복, receipt/resume/fork, TEAMMATE 및 전체 acceptance matrix는 제품 통합 수용 전이옵니다.
  • 6차 delta plan audit는 Opus API rate limit(HTTP 429)로 실행되지 않아 독립 PASS 판정이 없사옵니다.
  • status 268건은 이번 변경과 무관한 공유 세션 변경도 포함할 수 있으므로 commit·merge·push 완료를 뜻하지 않사옵니다.

Residual-risk

  • Claude Code가 native field 또는 event 종류를 추가하면 exact validator가 400/502로 닫힐 수 있사옵니다. 조용한 오라우팅은 줄이지만 새 버전의 자동 호환을 보장하지는 않사옵니다.
  • 공식 Responses 문서의 reasoning item 후속 입력 요구를 현재 gateway가 보존하지 않으므로 provider resume에서 문맥 손실 또는 upstream 거절이 남을 수 있사옵니다. OpenAI Responses streaming reference
  • 초기 tool 목록에서 deferred tool을 빼면 최초 prompt의 도구 가시성은 맞지만 후속 tool_reference 요청은 실패할 수 있사옵니다. Anthropic tool reference
  • thinking.display의 summarized를 GPT reasoning 응답으로 바꾸는 계약은 확인되지 않아 GPT profile에서 거절하옵니다. Anthropic Messages API

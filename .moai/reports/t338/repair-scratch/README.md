# iter-2 수리 검증 하네스 — 증거, 프로젝트 코드 아님

`plan-audit-iter2.md` 의 결함 11건을 수리 전에 **독립 확인**하는 데 쓴 스크립트다. 감사관의 `../iter2-scratch/` 와 같은 범주이며, 배포되지 않고 어디서도 import 되지 않는다.

두 하네스가 따로 있는 것은 의도된 것이다 — 감사관이 만든 것과 수리자가 만든 것이 **독립적으로** 같은 수치에 도달했는지가 판정의 일부이기 때문이다. 하나로 합치면 그 독립성이 사라진다.

## 품질 게이트가 여기 걸리면 무시한다

`../iter2-scratch/README.md` 와 같은 이유다. 재현 하네스는 돌던 그 형태로 보존해야 값이 있고, 린트를 만족시키려 손대는 순간 "그때 무엇을 돌렸는가"의 기록이 아니게 된다. 관측된 지적(한 줄 import, 변수명 `l`)은 읽기 전용 스캐너에서 스타일 외 의미가 없다.

고쳐야 할 것은 스크립트가 아니라 게이트가 `.moai/reports/**` 를 코드 경로로 훑는다는 점이고, 그것은 이 카드 범위 밖이라 관측으로만 남긴다.

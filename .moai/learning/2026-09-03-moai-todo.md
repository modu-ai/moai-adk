## 결론

`moai todo`는 MoAI 칸반의 **위임 채널**이다. 세션 간 메시지는 도착 보장이 없으므로, 실제 위임은 디스크 위 단일 큐로 이루어진다. 저장소는 JSON 단일 문서에서 SQLite로 전환됐고(`SPEC-TODO-SQLITE-001`), 전환 커밋 `18a2a6978`은 **어느 태그에도 포함되지 않음 = 미출시**.

## 동사 17개

| 동사 | 쓰기 | 요지 |
|---|---|---|
| `add <text>` | O | 카드 추가. `--pick`(추가+지명 원자적), `--force`(정확 중복 강제) |
| `list` | X | 큐 렌더. `--json`, `--limit`(기본 20), `--dropped` |
| `next [<n>]` | 조건부 | 인자 없으면 후보 나열(읽기), `<n>` 주면 picked 전이. `--spec`, `--expect` |
| `unpick <n>` | O | picked → queued |
| `done <n>` | O | 아카이브로 이동(카드+관련 finding). `--expect`, `--require-landed` |
| `undone <n>` | O | 아카이브 → 원위치 복원. id 재발급 시 거부 |
| `edit <n> <text>` | O | 텍스트만 교체, id/added_at/state/spec_id 보존 |
| `move <n>` | O | 순서 이동. `--top/--bottom/--before/--after` 중 정확히 1개 필수 |
| `drop <n> <reason>` | O | queued → dropped, 텍스트에 `[DROPPED — <reason>] ` 접두 |
| `undrop <n>` | O | dropped → queued, 접두 제거. state가 권위 |
| `analyze` | O(기록만) | 큐 전체 재분석, finding 기록. 카드 변경 없음 |
| `relate <a> <b> --relation` | O(기록만) | contains/absorbs/replaces/conflicts 관계 기록 |
| `unrelate <index>` | O(기록만) | finding 1건 제거 |
| `why <n>` | X | 해당 카드를 지목하는 모든 finding 출력 |
| `pr [<id>]` | X | 카드별 PR 연결/착지 상태. 5결과: linked/ambiguous/landed/no-link/unknown |
| `export-json` | O | 레거시 backlog.json 내보내기(다운그레이드 경로). 마이그레이션 역행 아님 |
| `history [<id>]` | X | 카드의 행방(live/archived/absent) 또는 아카이브 목록(기본 20) |

## 상태 모델

`queued → picked` (next), `queued → dropped` (drop), `* → archived` (done). 역방향 전부 존재: `unpick`, `undrop`, `undone`. `done`은 삭제가 아니라 아카이브 이동이므로 `undone`이 바이트 동일 복원을 보장한다.

## 저장소

- 엔진: `modernc.org/sqlite` (순수 Go, `CGO_ENABLED=0` 안전). 파일 `<queue-dir>/backlog.db`
- 포즈처: WAL journal, `busy_timeout=5000ms`, 트랜잭션 `IMMEDIATE`. 프로세스 내 단일 풀 커넥션, 프로세스 간은 외부 `backlog.lock` advisory lock
- 스키마 4테이블: `items`, `findings`, `archived_items`, `archived_findings` + `meta(schema_version, last_seq)`
- `items.seq`는 **id 번호가 아니라 배열 위치** — `move`가 순서를 바꾸므로 위치를 저장해야 순서 계약(REQ-TOSQ-004)이 성립
- 쓰기는 매번 items/findings 테이블 전량 교체(수백 행 규모라 마이크로초)
- SQL 문에 사용자 텍스트 보간 없음 — 전부 placeholder
- `BacklogPathForRoot`는 여전히 `backlog.json` 이름을 반환(호출자 계약 보존 + 다운그레이드 서사 유지)

### 지연 마이그레이션

레거시 `backlog.json`이 있으면 최초 접근 시 1회 흡수 후 `backlog.json.migrated`로 **rename 격리**(삭제·절단 없음).

### backlog.json은 큐가 아니다

`SPEC-BACKLOG-JSON-DISCLOSURE-001`(카드 t395). 정규 경로의 `backlog.json`은 조용히 오답을 준다. 작성자를 특정하지 못했으므로 **읽는 쪽**이 말하게 함 — `moai todo` 계열 verb는 stderr에 1줄 고지. stdout은 기계 표면(`--json`을 foreman 루프가 읽음)이라 바이트 동일 유지.

## 큐 루트 해석

`internal/kanban/todo_root.go`. 링크드 워크트리에서 실행해도 **PRIMARY 체크아웃**으로 해석 — git common dir의 부모가 primary 루트. git이 답 못 하면 `~/.moai/todo/<project-key>/backlog.json` 폴백.

두 진입점으로 분리(`SPEC-WEB-TODO-QUEUE-001`):
- `ResolveTodoQueueRoot` — **순수**. MkdirAll/Rename/WriteFile 없음. `internal/web`가 사용(콘솔이 페이지 렌더의 부작용으로 백로그를 마이그레이션하면 안 됨)
- `ResolveTodoQueueRootAdopting` — 해석 후 adopt. `moai todo` 명령 경로가 사용

read-through(D-2): 폴백 루트에 큐 파일이 없고 프로젝트-로컬 루트에 있으면 순수 리졸버도 프로젝트-로컬로 해석(여전히 쓰기 없음).

동기: 2026-08-17 실측 — primary에 30장, 링크드 워크트리에서는 "큐가 비었음".

## 분석기

`internal/kanban/backlog_analysis.go`. 순수 함수(스토어·파일·시계 없음).

- 판정 3종: `none` / `near` / `exact`
- 근사 중복 임계: **토큰집합 Jaccard 0.80**. 오차 비대칭이라 높게 설정 — 낮으면 finding이 카드보다 많아져 운영자가 목록을 안 읽게 되고, 이는 기능이 없느니만 못함. 놓치면 기능 도입 전 상태로 돌아갈 뿐
- **거절하는 유일한 분류는 `exact`** (정규화 텍스트 동일). `--force`로 강제 가능
- 텍스트만 본다. 같은 뜻 다른 표현은 `none` — 의미 판단은 에이전트 계층(`todo relate`) 몫이며 거기서는 결과가 거절이 아니라 기록

## 게이팅

`workflow.todo.enabled` (`internal/config/todo_enabled.go`, `SPEC-TODO-ENABLE-FLAG-001`).

- **부재 = 활성**. 그래서 `*bool` — 배포 템플릿에 todo 블록이 없으므로 "미설정"이 대다수 상태이고, 명시적 opt-out과 구분돼야 함
- `false`가 끄는 것은 **가이던스 표면**뿐(SessionStart 라인, statusline 세그먼트, 스킬 자동 라우팅). 명령은 계속 등록되고 모든 verb 동작
- nil-receiver safe, fail-OPEN. 빈 루트·`.moai` 부재·로드 에러 전부 true

## 운영자 경계 [HARD]

- 큐 진입은 운영자 행위(`add`). 지명도 운영자 행위(`next <n>`)
- 리드는 사전 선택 금지, 추론 우선순위 재정렬 금지, "맨 위 시작" 기본값 부착 금지
- 빈 큐는 정당한 상태 — 일을 발명할 신호가 아님
- 일괄 승인은 가능(카드 여러 장 지명 또는 "순서대로 소진"). 그건 한 번에 한 지명이며, 추가·재정렬 권한은 주지 않음
- 상시 발행원(standing source)은 **`/moai project` 하나뿐**. 5조건 전부 구속: 실행당 1장 · harness-spec.yaml에서 파생(발명 아님) · `[PROJECT] ` 접두 · 발행 id 보고 · 시작은 별도 지명
- TODO 주석, 이슈, 감사 결과, 리포트 마일스톤은 발행원이 아님

## 함정

1. `backlog.json`을 큐로 읽는 것 — 낡은 export. SQLite가 권위
2. `done` 기본 착지 판정은 `unknown` — `--require-landed` 없으면 질의 자체를 안 함. "가드 통과"와 "가드 미실행"은 다른 사실
3. `pr`의 `landed`는 "이 카드를 지목한 무언가가 착지"이지 "이 카드의 마지막 단계가 착지"가 아님
4. `pr`의 `unknown`은 not-landed의 증거가 아님
5. 한 단어 카드는 `add` 명시 필요 — 미지의 단일 토큰은 오타로 간주해 에러(오타가 카드가 되면 안 됨)
6. `moai todo pick t151` 형태(동사꼴 + 카드 id)는 폴스루 거부 — 오타난 동사로 판정

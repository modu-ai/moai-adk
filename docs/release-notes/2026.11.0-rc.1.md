- 작성: 2026-11-09, #2262.

## 무엇인가

MoAI ADK의 Rust 차세대 CLI `moai-cli` 첫 RC입니다. Claude Code와 Codex에서 공통 skill `skills/moai/`(`/moai`·`$moai`)로 진입하고, 내부 operation은 `moai-cli <subcommand>`가 envelope(`{protocol_version, operation, ok, result|error}`, exit 0/1/2)으로 응답합니다. operation 목록 전체는 `docs/design-review/appendix/interfaces.md` § RC1 OPERATIONS 전수에 있습니다.

## 지원 범위 (P04)

지원 대상은 **macOS arm64(`aarch64-apple-darwin`) × Claude Code·Codex**뿐입니다(사용자 결정 P04, #2262). 그 밖의 OS·arch·host는 미지원(후속)입니다. 지원 대상 안에서도 실제 host 로딩 E2E(T2)는 아직 운영자 실측 전이라 `not_run`입니다. 조합별 상태는 `docs/support-matrix.md`가 정본입니다.

## Go 세대(3.x)와의 격리

- Rust 상태는 `<project>/.moai-cli/`와 `~/.moai-cli/`에만 씁니다. Go 세대의 `.moai/`·`~/.moai/`·`.claude/`는 읽기만 하고 지우거나 덮지 않습니다.
- tag 이름공간은 `moai-cli-v*`입니다. Go updater가 보는 `/releases/latest`와 `v`/`go-v` 접두사 tag 어느 쪽에도 걸리지 않게 설계했습니다. 게시할 때는 `--prerelease --latest=false`로 올립니다. 게시 전 실측(2026-11-09): `/releases/latest` = `v3.1.2`(Go stable), `moai-cli-v2026.11.0-rc.1` release 없음.
- Go `moai` 바이너리는 이 RC가 자동으로 지우지 않습니다. 이주 경로(`moai-cli migrate --from-go`, 04-D #2016)는 RC1 범위의 설계이고, `~/.moai` 데이터는 보존하며 자격증명은 복사하지 않습니다.

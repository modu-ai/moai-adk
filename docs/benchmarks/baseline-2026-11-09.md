# RC1 benchmark baseline — 2026-11-09 (#2190, REQ-D4-01)

moai-cli 내부 연산의 최초 baseline 측정입니다. 비교는 이 baseline 이후의
측정에만 허용되고 절감률 발표는 금지됩니다(#2190 범위). 재실행은 아래
명령과 동일 조건(fixture·반복 횟수·빌드 프로파일)에서
`scripts/benchmark.sh 12 2`를 사용합니다.

## 명령

측정 대상 연산은 고정 fixture(임시 디렉터, v2 `project.yaml` + generation 요청 +
`skills/moai/workflows/`)와 저장소의 `skills/moai` 패키지입니다.

```sh
CARGO_HOME=/tmp/moai-rc-product-cargo CARGO_TARGET_DIR=/tmp/moai-rc-target-agent-8 \
    cargo build --offline --locked
CARGO_HOME=/tmp/moai-rc-project-cargo CARGO_TARGET_DIR=/tmp/moai-rc-target-agent-8 \
    bash scripts/benchmark.sh 12 2
```

harness: `scripts/benchmark.sh` — 각 샘플은 자식 프로세스로 대상 연산을
실행하며 wall time을 나노초로 기록합니다. RSS는 별도 샘플링 패스에서
`/usr/bin/time -l`을 같은 연산에 덧대어 측정합니다. fixture는 스크립트가
매 실행마다 임시 디렉터에 동일 내용으로 재생성하고 종료 시 폐기합니다.

## 알려진 제약

- 측정은 공유 개발 장비에서 이루어졌습니다 — 동시 세션 부하가 p95에 유입될 수

- debug 프로파일 기준값입니다. release 비교는 별도 실행으로 기록합니다.
- fixture 연산은 프로세스 기동(~6 ms)을 포함합니다 — 순수 연산 시간은 이보다
  작습니다.

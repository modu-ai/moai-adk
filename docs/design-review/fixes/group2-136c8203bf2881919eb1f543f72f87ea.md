## TOON 교체 완성문 (제외안 — decisions 01:2x(11-09))

조건부 채택안(안 B)은 decisions 01:2x(11-09)로 폐기했으므로 싣지 않는다. 이전 판의 두 안 병기는 이 파일의 git 이력(PR #2151 병합본)에 남아 있다.

### 제외 확정안 (L4436-4450 절 전체 교체)

> **TOON 적용 경계 (확정: 제외)**
>
> MoAI ADK의 모든 기계 판독 경로(CLI·manifest·receipt·journal·MCP typed JSON/JSONL, host native YAML/TOML)는 JSON 계약을 유지하고 TOON은 도입하지 않는다. 근거: (1) 모델이 읽는 반복 목록의 토큰 절감은 실측 전까지 가설이고, (2) hash/lock·audit 기록은 표현 불변의 byte·key·숫자 서술이 필요해 파생 포맷으로 대체할 수 없으며, (3) 외부 TOON 수신 시 strict parse→정규화→schema·domain 검증이라는 추가 경계 비용이 절감을 상쇄할 수 있다. 확정 출처: decisions 01:2x(11-09) "rc.2 발행 확정" 행 + 적용 일시 [Space 적용 시 기입]. FORMAT-ROUNDTRIP·FORMAT-BOUNDARY·FORMAT-HASH-PRESERVE·FORMAT-PROVENANCE·FORMAT-INJECTION·FORMAT-HOST-E2E·FORMAT-FALLBACK 후속 검증 7건은 제외 결정과 함께 폐기하되, 향후 재검토 요청이 오면 새 근거(URL·확인일)와 함께 다시 열어야 한다. 상위 문서 §13의 TOON 언급(L1395)도 같은 결정으로 정리한다. 근거 자료(TOON spec 4.4·Rust 구현 0.7.0·공식 benchmark)는 역사 근거로 부록에 남긴다.

### 상위 §13 L1395 한 줄 교체 (자리표시)

> **[적용 시 원문 확인 필요]** 현재 원문은 저장소에 사본이 없다(synthesis S6은 "조건부 채택 쪽 문구"라고만 기록). Space 적용 때 L1395 원문을 읽은 뒤 아래 뜻의 한 줄로 바꾼다. 원문을 보기 전에는 문구를 확정하지 않는다.
>
> 교체 뜻: "TOON은 도입하지 않는다. 모든 기계 판독 경로는 JSON 계약을 유지한다(Core Brain 'TOON 적용 경계', decisions 01:2x(11-09))."

### 후속 기록

> (1) 결정과 적용 일시를 상위 문서 §13·§18의 TOON 미결 행에 연결해 기록한다. (2) 저장소에는 TOON 관련 코드도 FORMAT-* 이름의 시험도 없다. tip `86762b8e1cb4fa7a3638e859331d41d542767f14`에서 `git grep -i toon -- src tests tools skills` 0줄, `git grep -E "FORMAT-(ROUNDTRIP|BOUNDARY|HASH-PRESERVE|PROVENANCE|INJECTION|HOST-E2E|FALLBACK)" -- src tests tools skills` 0줄이다. 따라서 "FORMAT-* 시험 삭제"는 설계 문서(Core Brain L4446)만 바꾸는 일이고 저장소 시험·코드 변경은 없다. (3) 외부 근거(TOON spec 4.4 URL, Rust 구현 0.7.0 crates.io URL)는 확인일을 붙여 부록에 남기거나 "미결"로 환원한다. 모델 기억으로 URL·버전을 채우지 않는다.

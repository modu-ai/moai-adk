## TOON 교체 완성문 (S6 양안 — 사용자 결정 대기)

### 안 A — 제외 확정안 (L4450의 결론을 본문 전체에 일관 적용)

> **TOON 적용 경계 (확정: 제외)**
>
> MoAI ADK의 모든 기계 판독 경로(CLI·manifest·receipt·journal·MCP typed JSON/JSONL, host native YAML/TOML)는 JSON 계약을 유지하고 TOON은 도입하지 않는다. 근거: (1) 모델이 읽는 반복 목록의 토큰 절감은 실측 전까지 가설이고, (2) hash/lock·audit 기록은 표현 불변의 byte·key·숫자 서술이 필요해 파생 포맷으로 대체할 수 없으며, (3) 외부 TOON 수신 시 strict parse→정규화→schema·domain 검증이라는 추가 경계 비용이 절감을 상쇄할 수 있다. 확정 일시·출처: 이 절을 교체하는 PR의 병합 커밋과 그 링크로 남긴다. FORMAT-ROUNDTRIP·FORMAT-BOUNDARY·FORMAT-HASH-PRESERVE·FORMAT-PROVENANCE·FORMAT-INJECTION·FORMAT-HOST-E2E·FORMAT-FALLBACK 후속 검증 7건은 제외 결정과 함께 폐기하되, 향후 재검토 요청이 오면 새 근거(URL·확인일)와 함께 다시 열어야 한다. 상위 문서 §13의 TOON 언급(L1395)도 같은 결정으로 정리한다. 근거 자료(TOON spec 4.4·Rust 구현 0.7.0·공식 benchmark)는 역사 근거로 부록에 남긴다.

### 안 B — 조건부 채택안 (L4436-4448의 위임 판단을 본문 전체에 일관 적용)

> **TOON 적용 경계 (확정: 조건부 채택, 위임 판단)**
>
> 저장·설정·외부 인터페이스는 기존 호환 형식(JSON 계약)을 유지한다. 모델이 읽는 반복적인 task·symbol·finding 목록에서만 TOON을 선택적으로 검토하고, 실제 데이터의 토큰·정확도·지연·파싱/재시도 비용을 FORMAT-ROUNDTRIP·FORMAT-BOUNDARY·FORMAT-HASH-PRESERVE·FORMAT-PROVENANCE·FORMAT-INJECTION·FORMAT-HOST-E2E·FORMAT-FALLBACK 7개 시험으로 검증한 뒤 적합한 경우에 채택한다. 부적합·미지원·시험 미충족이면 JSON으로 fallback하며 이 경계에서 다시 판단하지 않는다. 확정 일시·출처: 이 점을 교체하는 PR의 병합 커밋과 그 링크로 남긴다. L4450의 "절대 도입하지 않는다" 문장은 본 절과 모순되므로 삭제한다(작성 주체가 다른 덧붙임으로 판정). MCP structuredContent는 JSON object 계약 유지, byte·row·field·depth·시간·메모리 상한과 TOON spec 4.4·Rust 구현 0.7.0의 버전 pin은 그대로 유효하다. 상위 문서 §13의 TOON 언급(L1395)도 이 결정으로 정리한다.

### 공통 후속 행 (양안 공통)

> 어느 안을 선택하든: (1) 선택과 일시를 상위 문서 §13·§18의 TOON 미결 행에 연결해 기록하고, (2) RC1 실물에는 TOON 관련 코드가 없음(`604792666` src 전체 검색 0건 — 검토 ① §4 가설 표기 유지)을 근거로 남긴다. 외부 근거(TOON spec 4.4 URL, Rust json_stream 0.7.0 crates.io URL)는 확인일을 붙여 부록에 남기거나 "미결"로 환원한다 — 모델 기억으로 URL·버전을 채우지 않는다.

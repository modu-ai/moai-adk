## 요약

설계 원칙(근거 없는 PASS 금지, 승인 분리, single writer, 비벡터 우선, Go 격리)은 RC1이 실제로 지킨 방향과 같다. 고쳐야 할 것은 원칙이 아니라 **문서와 RC1 실물 사이의 어긋남**이다. ① 이미 결정된 항목을 "남은 결정"으로 적고, ② 디렉터리·스키마 이름이 RC1에서 출하된 것과 다르며, ③ 실행 순서가 §1의 첫 RC gate와 맞지 않고, ④ RC1 Rust 코드(70여 PR)를 근거로 한 줄도 인용하지 않는다.

## C. 잘 되어 있어 유지할 점

- "검색 결과·모델 요약은 원문 권위를 대체하지 않는다", "not_run을 PASS로 승격 0", "timeout 뒤 중복 Issue/PR 0" — RC1 감사에서 실제로 걸러낸 결함(#2099 reconcile 거짓 부재, #2104 빈 sweep 통과)과 정확히 같은 원칙이다.
- 승인 분리(commit·push·Issue 공개·PR·merge·release)와 Go 상태 격리는 RC1 결정과 일치한다.
- "Host별 설치본은 독립 복사, symlink 계승 안 함"은 03-B HOLD-2(복사) 확정과 일치한다.

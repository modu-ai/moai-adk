# `home-install-plan`

operation `home_install.plan` · 코드 `src/ops/home_install_plan.rs`, `src/home_install.rs` · Issue #2871 (U3a)

`home-install-plan [--home DIR] [--now UTC] [--project DIR]` 는 `~/.moai-cli` 의 맨 위 항목마다 HOME 이름 표(`home_layout::HOME_TABLE`)로 동작을 정한다: `move`(이 세대가 쓰는 이름 — `~/.moai/<이름>` 으로 rename), `keep`(이유 `user_data`·`worktrees_stay`·`not_written_by_this_generation`·`not_in_table`·`marker_written_last`·`install_journal`·`link`·`special_file`), `blocked`(`~/.moai` 에 같은 이름이 이미 있음, 이유 `destination_taken` — 이름 목록은 대소문자만 접어 비교하고, 그 밖의 접힘(유니코드 등)은 파일 시스템에 `~/.moai/<이름>` 을 `lstat` 으로 직접 물어 잡는다). 판정이 `none`·`empty`·`go`·`mixed` 일 때만 옮길 수 있고, 아직 은퇴하지 않은 Go 항목이 있으면 막는다(`go_items_not_retired` — 먼저 은퇴, 그다음 설치). 판정이 `rust`·`rust-first` 인 HOME 은 이미 옮긴 것이라 `~/.moai-cli` 에 다시 쓰인 항목을 `late_arrivals` 로만 보여 준다(병합은 뒤 조각).

함께 모으는 사실(모두 메타데이터만, 아무것도 열지 않는다): 버전 폴더마다 이동 전후 설치 id(`alias_table`, 설치 id 는 바이너리 정규 경로의 해시라 폴더가 옮겨지면 바뀐다; `bin/moai-cli`(Windows 는 `.exe`)가 없거나 버전 폴더·`bin` 이 링크인 폴더는 `alias_skipped`), `path` 항목을 어디로 다시 가리킬지(`stub`), vault 폴더·마스터 키의 모드와 항목 수(`vault`, `loose` 는 0700/0600 보다 느슨함). 막는 것: 판정 `unknown`·`interrupted`·`refuse`, `~/.moai-cli` 가 링크·폴더 아님, `MOAI_HOME` 이 다른 곳, 같은 stamp 의 저널이 이미 있음, 다른 파일 시스템, 항목 500개 초과, 별칭표·`path` 스텁 목록이 한도(버전 폴더 500개·`path` 항목 50개)를 넘어 잘림(`versions_not_fully_listed`·`path_not_fully_listed` — 조용히 자르지 않고 막는다), 읽을 수 없는 이름·폴더(`unreadable_names`·`state_dir_unreadable`·`destination_unreadable`), 은퇴 미리보기가 막혀 Go 항목이 다 은퇴했는지 알 수 없음(`go_retire_preview_blocked`). `sessions`(U3c, 리더 결정 6886405676)는 `--project`(기본 현재 폴더)가 속한 클론의 세션 레지스트리를 읽어 `checked`(레지스트리 경로, 못 찾으면 null)·`live`(살아 있는 Rust 세션 수, 못 읽으면 null)·`error`·`other_clones: "not visible from the HOME"` 를 보여 준다 — 다른 클론의 세션은 HOME 에서 볼 수 없다는 뜻이고, 어느 digest 에도 들어가지 않는다(적용이 직접 다시 판단한다). 항목 500개 한도는 적용이 잠금용으로 만드는 `home-install` 저널 폴더를 세지 않는다(없던 폴더가 생겨도 계획이 달라지지 않게). 아무것도 쓰지 않고 `plan_digest`·`content_digest`·확인 토큰(`install:` + 16자리)을 돌려준다. 적용은 `home-install-apply`, 되돌리기는 `home-install-revert`. 토큰은 시계와 상관없이 판정·항목의 `dev:inode`·별칭표·스텁·vault 에서만 만들어진다.

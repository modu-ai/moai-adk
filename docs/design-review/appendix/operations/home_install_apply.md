# `home-install-apply`

operation `home_install.apply` · 코드 `src/ops/home_install_apply.rs`, `src/home_install_apply.rs` · Issue #2871 (U3c)

`home-install-apply --home DIR [--project DIR] --now UTC --plan-digest D --permission-reference REF` 는 `~/.moai-cli` 의 이 세대 항목을 `~/.moai` 맨 위로 옮긴다. `--home` 은 필수이고 실제 HOME 이 기본이 되는 일은 없다. 같은 입력으로 다시 계산한 `home-install-plan` 의 `plan_digest` 가 같고 `action` 이 `install` 일 때만 움직인다(아니면 `stale_plan` 등으로 거절하고 아무것도 쓰지 않음).

순서: 허가 참조 → 저널 폴더 `~/.moai-cli/home-install/` 가 진짜 폴더인지(링크·파일이면 거절, 잠금·매니페스트를 쓰기 전에) → 이 `--now` 의 매니페스트가 있으면 그 상태로 판단(끝났으면 `unchanged`, 멈췄으면 새 미리보기 없이 이어서 하기, 되돌려졌으면 거절; digest 는 매니페스트의 것과 같아야 함) → 없으면 새 미리보기와 digest 비교, 다른 stamp 의 멈춘 설치가 있으면 거절, 저널이 64개면 거절(65번째는 가장 오래된 저널의 설치 id 를 조회에서 밀어냄) → `--project` 클론에 등록된 Rust 세션(`<클론 공통 폴더>/.moai-cli/sessions/` 의 살아 있는 항목과 `.live` 잠금)이 있으면 `home install blocked: rust_session_live:<n>`, 레지스트리를 못 읽으면 닫힌 채로 `rust_session_registry_unknown` → 설치 잠금 `home-install/apply.lock`(기다리지 않음, 쥐고 있으면 `conflict in home install`) → 잠금 안에서 같은 판단을 한 번 더 → 불변 매니페스트 `install-manifest-<UTC>.json`(항목·별칭표·링크·vault 사실·표식 바이트) → `~/.moai` 만들기(없을 때만, `~/.moai-cli` 와 같은 모드) → 이동 저널 `move-journal-<UTC>.json`(kind `home-install`)에 따라 항목마다 배타 rename 1회(`versions` 와 `path` 는 맨 마지막, 돌고 있는 프로그램이 쥔 항목은 건너뜀 — `versions`·`path` 는 실행 중인 빌드가 있어 예외) → 하나라도 못 옮겼으면 옮긴 것을 되돌리고 `state: rolled_back`(처리 못 한 표를 읽을 수 없을 때도 같음) → `path` 의 링크 중 계획이 `repoint:true` 인 것을 임시 링크를 만들어 rename 으로 덮어 새 `versions` 로 다시 가리키기(이미 새 대상이면 그대로) → vault 를 `lstat` 으로만 다시 재서 이동 전 사실과 비교(느슨해도 `chmod` 하지 않고 알리기만, 열지 않음) → schema 2 표식(`state_root::home_marker_bytes`)을 맨 마지막에 배타적으로 써서(파일 이름은 매니페스트에 저장된 표식 바이트의 `generation` 이 정한다: 새 설치는 `moai` 라서 `moai.json`, 앞 빌드가 시작해 저장한 `moai-cli` 는 `moai-cli.json`, 그 밖의 값이면 거절 — 이어받기·`unchanged` 판단·되돌리기가 모두 같은 이름을 쓴다, #2871) `home_root::dir` 이 `.moai` 로 바뀌는 순간이 전부 끝난 뒤가 되게 함.

중간에 멈춘 설치는 같은 `--now`·`--plan-digest` 로 다시 실행하면 이어서 끝난다. 복사도 삭제도 없고, 비밀은 이름과 모드만 본다. 디버그 빌드는 `MOAI_CLI_TEST_INSTALL_FAULT=<지점>` 으로 지점마다 멈출 수 있다(`after_manifest`, `after_mkdir`, `after_journal`, `after_mark_moving`, `after_rename`, `after_move:<n>`, `before_commit`, `after_commit`, `after_stub:<n>`, `before_marker`, `after_marker`); 릴리스 빌드에는 없다. 실제 HOME 에서는 사용자 확인 뒤 리더만 실행한다.

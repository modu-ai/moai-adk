# `project-update-plan`

operation `project.update_plan` · 코드 `src/ops/project_update_plan.rs`, `src/project_update.rs` · Issue #2936 (S1, 계획 6876732470, 리더 결정 6876725450)

`project-update-plan PROJECT` 는 프로젝트 `/moai update` 의 전체 미리보기를 한 번에 보여 준다. 쓰지 않는다. 각 단계는 이미 있는 plan 을 같은 프로세스 안에서 부르고, 그 plan 의 apply 명령을 그대로 적어 준다.

- `phases`: 사용자 UPDATE 흐름(#2936 6876720048)의 세 단계, 순서대로 `backup`·`install`·`merge`. 단계마다 `phase`, `state`(그 안의 가장 나쁜 step 상태: `unchanged` < `skip` < `ready` < `needs_decision` < `conflict` < `blocked`), `reason`, `steps`.
  - `backup`: `go-state` 한 step(`go_state::plan` 그대로). 옮길 것이 있으면 `needs_decision`(사용자에게 먼저 묻는다, PROJECT 2단계). `.agents`·`.codex`·설정·지침 파일은 아직 다루지 않는다(S2, `reason` 에 적음).
  - `install`: `profile`(저장된 프로필 + 지금 감지한 사실로 `project-plan`), `generation`(AGENTS.md 관리 구간과 생성 파일, `generation-plan`), `claude-settings`(MoAI 가 이미 가진 키에서 `hooks` 를 뺀 묶음, Q2 A. #2936 R8: 소유 기록에도 파일에도 `statusLine` 이 없으면 `{"type":"command","command":"moai-cli statusline"}` 를 더한다 — 사용자가 이미 둔 상태줄은 그대로 두고, `outputStyle`·`permissions`·`env`·`model` 은 기본으로 넣지 않는다), `github`(`github-plan` `{"protocol_version":1}`;   - `merge`: `agents-local-merge`(#2936 R10, `AGENTS.local.md` 를 `AGENTS.md` 로)와 `claude-settings-merge`(#2936 R8, 코드 `src/claude_settings_merge.rs`). 뒤의 것은 `go-state-apply` 가 Go 세대 `.claude/settings.json` 을 백업으로 옮긴 경우에만 일한다(#2936 S-CYCLE: Go 매니페스트가 `template_managed`/`user_modified` 로 기록한 설정은 증명된 것이라 `.moai/` 를 가리켜도 스스로 백업으로 옮겨지고, 그 설정만 가리키던 파일(`freed_by`)도 함께 옮겨진다. 기록이 없거나 `user_created` 이거나 링크이거나, 설치 단계가 쓴 파일(Rust 설정 영수증 `manifests/claude-settings.json` 이 키를 소유)이면 증명되지 않은 것이라(같은 Go 매니페스트로 두 번 옮기지 않는다) 옛 규칙대로 `.moai/` 폴더를 붙잡고 이 step 은 `skip`). 설정이 옮겨진 뒤 `hooks` step 은 Go 훅 항목이 설정과 함께 사라졌으므로 `hooks-apply --host claude`(MoAI 훅 묶음)를 `ready` 로 내놓는다 — 되돌려진(reverted) 이동의 영수증으로는 내놓지 않는다. 백업 사본(영수증의 sha256 과 같아야 함, 아니면 `blocked`)을 읽어 키마다 `preview.candidates[]` 에 `key`·`state`(`mergeable`·`kept_in_backup`·`go_generated`·`blocked`)·`reason`·`summary` 를 싣고 자격 증명 모양 값은 싣지 않는다. 가져올 수 있는 키는 `permissions`(allow·deny·ask 와 좁히는 `defaultMode`), `env`(자격 증명 이름·모양이 아닌 항목), `model`, 사용자 `statusLine`·`outputStyle`; `hooks`(MoAI 의 통째 키)·Go 가 심은 값·그 밖의 키는 백업에 남는다. 가져올 것이 없으면 `skip`, 있으면 `needs_decision` 이고 적용 명령은 기존 `claude-settings-apply` 이며 stdin 은 소유 키 + 가져올 수 있는 후보 전부다(일부만 가져오려면 `claude-settings-plan` 을 그 부분집합으로 다시 돌린다). `claude-settings` 가 `ready`·`needs_decision` 이면 후보가 있어도 `blocked: re-run after the install phase`. `settings.local.json` 은 읽지도 쓰지도 않는다.
- step: `step`, `state`(`ready`·`unchanged`·`conflict`·`needs_decision`·`blocked`·`skip`; `skip_in_use` 는 S2b 용으로 예약만 하고 내보내지 않음), `reason`, `preview`, `plan_digest`, `apply`. `apply` 는 적용할 수 있는 step 에만 `{"argv":[…],"stdin":<json|null>}` 이고 나머지는 `null`. `argv` 는 `moai` 로 시작하는 낱말 목록이고 자리표시자는 `<permission-reference>` 하나뿐이다.
- S-CYCLE 미리보기(#2936): `go-state` 미리보기에 증명된 설정이 옮겨질 때만 `settings_move`(`path`·`proof`·`edited`·`layout`·`freed`·`folder_freed`·`still_holding`)가 붙는다. 훅 항목·deny 규칙·상태줄은 개수로만, 규칙·명령·환경 값 문구는 싣지 않는다. 설정 설치 순서: `claude-settings` → (다시 미리보기) → `hooks` → (다시 미리보기) → `claude-settings-merge` — 세 step 이 모두 settings.json 바이트를 묶으므로 하나를 적용하면 나머지 digest 가 낡아 매번 다시 미리본다.
- 막힘 규칙: 한 step 의 오류는 그 step 만 `blocked`(이유에 오류 문구). `backup` 에 옮길 것이 남아 있으면 `install` 의 모든 step 이 `blocked: re-run after the backup phase`. 프로필이 없으면 `install` 의 모든 step 이 `needs_decision: run /moai project`(프로필은 만들지 않음, Q5). `profile` 이 `ready` 이면 `generation` 은 `blocked: re-run after the profile apply`(generation plan 이 프로필 바이트를 묶음).
- `generation` 요청: 언어는 프로필 `language.instruction_files` 가 `en`·`ko` 면 그것, 아니면 `en`; `workflow_reference`·`workflow_id` 는 생성 manifest 의 기록, 없으면 `<state>/workflows/project/`·`project`; `local_file` 은 manifest 가 `.gitignore` 의 `moai-local` 구간을 가지면 `ignored`, 아니면 `none`. manifest 가 요청이 기록되지 않은 프로젝트 에이전트·스킬(`generation:native-role:`·`generation:project-skill:`·`generation:skill-projection:`)을 가지면 `needs_decision`(Q1 A: `remove` 를 계획하지 않음, `preview.not_rebuilt` 에 경로).
- 그 밖: `project`(정규 경로), `detected`(감지 사실, 실패 시 `null`), `state_root`, `all_unchanged`(`backup`·`install`·`merge` 의 모든 step 이 `unchanged` 또는 `skip`).

자리표시자 프로필(#2936 R3): `generation` 단계는 프로필이 첫 실행의 자리표시자 그대로면 `needs_decision` 으로 멈추고 `/moai project` 를 안내한다. 적용 명령은 나오지 않는다(`generation-apply` 가 거부하는 계획을 보이지 않으려는 것).

# `home-routing-apply`

operation `home.routing_apply` · 코드 `src/ops/home_routing_apply.rs`, `src/home_routing.rs`, `src/home_routing/rules.rs` (#2638, SPEC-20261122-claude-md-home-routing)

`home-routing-apply HOME PACKAGE --plan-digest D --permission-reference R [--config-dir ABS]... [--remove-old-block]` 는 같은 선택으로 다시 계획해 digest 가 같을 때만 쓴다(`moai update` 에서는 그 확인 토큰이 사용자의 선택이다). 폴더마다 `rules/moai.md`, `rules/moai/flow.md` 의 `create`·`merge` 를 01-B 발행 엔진으로 쓰고, `--remove-old-block` 이 있고 계획이 `remove` 인 폴더에서만 옛 블록 범위 하나를 `CLAUDE.md` 에서 지운다(그 밖의 바이트는 그대로). 없던 폴더는 만들고 영수증에 적는다. 충돌·`blocked`·`waiting`·`kept` 는 쓰지 않는다. 영수증 `HOME/.moai-cli/home-routing/receipts/<id>/receipt.json`(pending → committed)은 항목마다 `host`, `kind`(`routing`·`flow`·`old_block`), `config_dir`, 동작, before/after sha256, 앞 기준, 만든 폴더 목록을 적고 before 바이트 사본(`<kind>-<폴더 id>.before`)을 남긴다. 설정 폴더별 소유 기록 `home-routing/rules-<id>.json` 을 갱신하고, 블록을 지우면 옛 기준 `home-routing/claude.json` 은 비운다. 결과: `state`(`applied`·`unchanged`), `plan_digest`, `receipt`, `written`(쓴 파일 경로).

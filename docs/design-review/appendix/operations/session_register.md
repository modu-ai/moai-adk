# `session-register`

operation `session.register` · 코드 `src/ops/session_register.rs`, `src/lane_registry.rs` · Issue #2592 S-C (리더 결정 6856973444 = (가) 이름 등록부, 설계 6850553121)

`session-register PROJECT --name NAME [--instance ID] [--lease-secs 3600] [--release] [--now T]` 는 레인 이름을 clone 공통 폴더의 등록부 `<clone common dir>/.moai-cli/sessions/<NAME>.json`(`-a` 번호 매기기와 같은 폴더, 모든 worktree 가 같이 본다)에 적는다. 같은 이름이 lease 안에 다른 instance 로 이미 있으면 `conflict`(`conflict in session registry: name … is in use by another instance until <UTC>`)로 거부하고 아무것도 쓰지 않는다. 그 instance 의 id 는 보여 주지 않는다. 첫 호출(`--instance` 없음)은 새 `instance`(16진수 32자)를 만들어 돌려준다. 같은 세션은 wake 마다 그 값을 `--instance` 로 넘겨 lease 를 늘린다(`renewed`). lease 가 끝난 항목은 누구나 새로 등록한다(`previous: expired`). `--release --instance ID` 는 그 instance 가 가진 이름을 지운다(`released`; 항목이 없거나 lease 가 끝났으면 `already_free`, 다른 instance 면 `conflict`). 세션을 비우기 전에 쓴다. 이름은 `A-Z a-z 0-9 . _ -` 1~64자이고 첫 글자는 영문자나 숫자다. lease 는 60~86400초다. 쓰기는 `registry.lock` 의 배타 `File::lock` 아래에서 임시 파일 → rename 으로 한다. 링크·일반 파일이 아닌 것·4 KiB 넘는 것·형식이 틀린 항목은 거부하고 덮어쓰지 않는다. 결과: `status`(`registered`·`renewed`·`released`·`already_free`), `previous`(`none`·`expired`·`same_instance`), `name`, `instance`, `lease_until`(UTC), `entry`. 막는 범위는 같은 기기·같은 clone 이다. 다른 기기의 같은 이름은 막지 못한다(설계 (나)의 몫).

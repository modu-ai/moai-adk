# `agents-project-plan`

operation `agents_project.plan` · 코드 `src/ops/agents_project_plan.rs`, `src/omp_agents.rs` · Issue #2936 (R9 S3·S5d, 사용자 결정 6880072221 Q-H1·Q-H4)

`agents-project-plan PROJECT PACKAGE AGENTS` 는 원본 폴더 `AGENTS`(스킬 밖 `agents/`, #2721)의 `*.md` 를 OMP 용으로 그려(`agent_defs::render(def, "omp")`; `reads:` 항목은 `PACKAGE/references/` 에서 확인) 프로젝트의 `PROJECT/.omp/agents/moai-<역할>.md` 와 3자 비교(기준 = 마지막 적용이 프로젝트 상태 폴더의 `manifests/omp-agents.json` 에 기록한 sha256, 현재 = 디스크, 새 것 = 렌더 결과)한다. OMP 는 프로젝트 `.omp/agents` 를 읽고 `.claude/agents` 는 읽지 않는다(조사 6881575127). 파일마다 `create`, `update`, `unchanged`, `preserved`(사용자 수정, 렌더 결과는 그대로), `conflict`(사용자 수정 + 렌더 결과도 바뀜, 또는 우리가 쓴 적 없는 같은 이름 파일), `remove_blocked`(우리가 쓴 파일인데 패키지가 더는 안 만듦: 알리기만 하고 지우지 않는다). 다른 이름의 사용자 에이전트(`reviewer.md` 등)는 읽지도 목록에 넣지도 않는다. `.omp`·`.omp/agents`·상태 폴더가 링크이거나 폴더가 아니면 `preflight` 가 `blocked`(`blocked_reason`). 아무것도 쓰지 않는다. 결과: `schema_version`, `host`, `project`, `dir`, `package_digest`, `agents_digest`, `preflight`, `blocked_reason`, `files`, `not_supported`, `shadows_user_agents`(프로젝트 에이전트가 `~/.omp/agent/agents` 의 같은 이름 사용자 에이전트를 가린다는 안내, Q-H4), `writes`(`false`), `plan_digest`(프로젝트 경로를 묶는다: 같은 구성의 다른 프로젝트에는 쓸 수 없다).

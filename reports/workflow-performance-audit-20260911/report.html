F05High구현 대조 · sync 보안

08. Claim · Baseline · Gaps · Residual risk

Claim — 이 보고서가 주장하는 것

문서/소스 대조와 격리 동작 재현을 근거로 40개 검토 항목을 제시했다. 84개 규칙의 전수 기계 조사와 핵심 관련 조항의 의미 대조를 수행했다. 모든 의미적 결함을 빠짐없이 찾았다는 보증은 아니다.

dirty 작업 트리를 그대로 읽었다. 이미 변경된 설정과 untracked 규칙도 현재 표면으로 포함했다. 제품 소스·지침·설정은 수정하지 않았고, commit/push/PR도 실행하지 않았다. 설치된 moai binary는 이 소스 HEAD와 빌드 기준이 다르다.

Gaps — 관찰하지 않은 범위

실제 project→sync 전체 실행, native Stop JSON 처리, 외부 취약점 DB 조회, 현재 원격 branch 보호, 실제 모델 가격·토큰·대기/실행 시간, 모든 언어별 검사, template/mirror 전체 동등성. 전수 규칙 파일 검사는 모든 규칙의 모든 분기 실행과 동의어가 아니다.

Residual-risk — 남는 위험

157개 해시가 같아도 범위 밖 파일·원격 상태·동시 세션은 달라질 수 있다. 문서 모순의 실제 해석은 harness와 호출 입력에 달려 있다. D7/D8 예제의 오탐·누락을 재현했으나 LLM의 최종 판정은 재현하지 않았다. 권한·독립 감사·보안·접근성 검사를 비용 절감 명목으로 제거해서는 안 된다.

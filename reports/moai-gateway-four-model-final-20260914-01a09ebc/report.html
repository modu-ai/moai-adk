Executive decision

최종 결정

메인 모델은 세션에 속하고, 카드 책임은 lane에 속하며, 이종 모델은 MCP의 제한된 작업 호출로만 들어온다.

1

메인 세션

moai cc, moai gpt, moai glm 중 하나. 선택한 backend·model·effort가 세션 정체성이다.

2

Factory lane

lead가 카드를 배정하고 lane이 plan → run → sync 전체를 끝까지 책임진다.

3

MCP 전문 호출

다른 회사 모델은 짧고 독립적인 상담·실행·교차 검토에만 쓴다. lane 정체성은 바꾸지 않는다.

폐기한 설계: lead, plan, run, routine, scan 같은 역할마다 GPT 모델을 고정하는 표는 MoAI Factory와 맞지 않는다. 역할별 GPT 이름도 API나 agent preset으로 만들지 않는다.

Kanban은 제품상 폐기 확정

현재 develop에 남은 -k는 지원 기능이 아니라 제거가 덜 끝난 레거시다. 이 설계 보고서는 상태를 미화하지 않고 별도 제거 카드가 필요한 GAP으로 기록한다.

  • internal/cli/cc.go의 도움말과 dispatch
  • internal/cli/factory.go의 -k/-f 병합 파싱
  • .claude/rules/moai/workflow/kanban-dispatch*.md
  • manager-lead.md와 이전 factory workflow 설명

별도 제거 acceptance: CLI·규칙·도움말·테스트를 함께 없애고, -k가 명시적인 지원 중단 오류를 내며 정상 기능으로 검색되지 않아야 한다.

Reference analysis

Proxy의 장점만 흡수

claude-code-proxy는 좋은 변환 참고서지만, 그 인증·비공개 endpoint 경로까지 제품 권한 원천으로 복제하면 위험이 커진다.

흡수한다

  • Anthropic ↔ provider 요청·stream 변환
  • provider별 모델 라우팅과 종료 사유 정규화
  • 세션 연속성·진단·redacted trace
  • golden fixture 기반 호환성 회귀 테스트
  • 이미지 기능을 텍스트 turn과 분리하는 발상

생산 경로에서는 버린다

  • 자체 OAuth 구현과 token lifecycle 소유
  • 비공개 ChatGPT endpoint 직접 호출
  • 무인증 loopback listener
  • 추정 token을 billing truth로 취급
  • 요청 모델을 다른 모델로 조용히 대체

실제 연결 방식

Claude Code의 Anthropic Messages 요청을 받아 Codex 요청으로 변환하고, 자체 OAuth 자격 증명으로 chatgpt.com/backend-api/codex/responses 계열 내부 경로를 직접 호출한다. 모델 라우팅, 스트리밍 변환, 토큰 추정, 대화 연속성, 진단을 제공한다.

Implementation order

남은 것만 구현

이미 merge된 launcher·inherit·effort 범위를 반복하지 않고, 미완료 production seam과 MCP 계약부터 닫는다.

M0

문서와 제품 표면 정합성

Kanban 폐기를 canonical 문서에 반영하고 -k 제거를 별도 카드로 분리. Factory 단일 정의 확정.

M1

App Server production turn cutover

OpenAIAdapter + AuthPKCE를 official App Server authority/adapter로 교체. t842 catalog와 resolver 공유.

M2

MCP V2 계약

Codex model·effort·project root·explicit thread, 결과 envelope, error taxonomy. V1 호환 필드는 유지.

M3

GLM 의미 정합성

provider-native thinking과 명시 모델 보장. Coding Plan entitlement와 일반 API 계약 분리.

M4

job·lane 안전성

session/lane/project identity, restart reconciliation, orphaned, explicit resume, worktree 경계.

M5

이미지 capability gate

별도 tool, exact gpt-image-2.5 provenance, redaction, 미확인 fail closed.

M6

Factory 운영 acceptance

t844·t848·t850/t851과 연결해 실세션·effort·400·usage receipt를 관찰하고 내부 benchmark 축적.

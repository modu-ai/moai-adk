Decision

조건부 GO

Claude Code에서 GPT‑6 응답·모델 선택기·Read 도구 왕복이 모두 실제로 성공했다. GLM도 기존 moai glm에서 실호출과 도구 왕복이 성공했다. 기술적 가능성은 확인됐으나, GPL 코드를 Apache-2.0 본체에 직접 편입하는 방식은 승인 대상이 아니다.

Executive Summary

할 수 있는가, 그리고 어떻게 해야 하는가

답은 “할 수 있으나, 그대로 복사해서는 안 된다”이다. 안전한 최초 사용자 여정은 moai gpt setup으로 설치·GPL 고지·인증을 마친 뒤 moai gpt로 실행하는 명시적 2단계다. 내부적으로는 시스템 CA나 /etc/hosts를 건드리지 않는 loopback HTTP gateway를 띄우고 Claude Code에 임시 설정과 환경을 주입한다.

가장 단순한 안전 경로GPT는 독립 GPL companion으로 제품화하고, GLM은 이미 검증된 moai glm을 유지한다. 통합 provider는 같은 세션에서 GPT↔GLM 전환이 꼭 필요할 때만 추가한다.

Target Architecture

Apache 본체와 GPL companion을 분리한다

최초 1회 사용자는 moai gpt setup으로 GPL 고지·설치·Codex 인증을 마친다. 이후에는 moai gpt가 검증된 companion을 자식으로 띄우고 readiness 뒤 Claude Code를 실행하며, 종료 시 정확한 PID와 임시 설정을 정리한다.

flowchart LR
  U[사용자: moai gpt] --> M[moai · Apache-2.0]
  M -->|digest 검증·spawn·supervise| P[moai-proxy · GPL-3.0]
  M -->|임시 settings + ANTHROPIC_BASE_URL| C[Claude Code]
  C -->|Anthropic Messages · loopback HTTP| P
  P --> R{fail-closed provider registry}
  R -->|GPT| O[ChatGPT Codex Responses]
  R -. 선택 기능 .-> Z[Z.AI GLM]
  G[moai glm · 기존 직결] --> Z
  M -->|signal·exit code·cleanup| C
왜 평문 loopback인가실측에서 ANTHROPIC_BASE_URL=http://127.0.0.1:<port> 방식이 GPT‑6와 [1m] client context 모두 성공했다. 따라서 기본 설치가 system CA, /etc/hosts, privileged port를 변경할 이유가 없다.
Delivery Plan

단계별 구현 계획

라이선스·제품 경계

GPL 독립 저장소·릴리스, source 제공, LICENSE/NOTICE, 수정 고지를 먼저 확정한다. Apache-only가 필수면 별도 허락 또는 clean-room으로 전환한다.

상류 포크 하드닝

Go 1.26.6+, govulncheck 0건, PR/main CI, Actions SHA pin, SBOM·attestation·signed checksum을 적용한다. HTTP-only에서 CA를 만들지 않고 shell eval 표면을 제거한다.

호환성·보안 재기준화

공식 Codex 모델·effort·OAuth·헤더 계약으로 profile을 다시 만든다. unknown route는 실패시키고, credential은 lock+reread+fsync+atomic replace 또는 전용 저장소로 격리한다.

MoAI 명령 통합

명시적 2단계를 고정한다. 최초 moai gpt setup은 GPL 동의 뒤 POSIX ~/.local/share/moai/bin/moai-proxy 또는 Windows %LOCALAPPDATA%\MoAI\bin\moai-proxy.exe에 설치하고, auth가 없으면 proxy login을 실행한다. 이후 moai gpt가 실행을 담당한다. 취소 시 부분 설치를 제거하고, update readiness 실패 시 직전 binary로 되돌린다.

GPT‑6 E2E와 플랫폼 릴리스

단문·stream·도구·thinking·picker·오류·정리를 검증하고 6개 OS/arch 실제 smoke를 릴리스 SHA에 귀속한다. 장문맥과 비용은 별도 승인형 canary로 측정한다.

선택적 GLM provider

기존 moai glm보다 분명한 가치가 있을 때만 같은 세션 전환을 추가한다. Z.AI Anthropic-compatible payload는 불필요하게 Codex translator를 거치지 않는다.

Final Recommendation

독립 GPL companion이면 진행, Apache-only 단일 배포면 중단

Claude Code에서 GPT‑6를 쓰는 핵심 경로와 기존 MoAI의 GLM 경로는 모두 실제로 작동했다. 따라서 핵심 기술 경로의 가능성은 확인됐다. 다만 첫 구현은 translator 복사가 아니라 GPL 경계, Go 보안 갱신, Codex 계약 재기준화, fail-closed 설치와 자식 프로세스 감독이어야 한다.

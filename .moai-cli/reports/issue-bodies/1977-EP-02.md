# [RC1][EP-02] Rust 실행과 저장

## 목표와 사용자 가치
moai-cli(Rust)가 프로젝트·worktree를 틀리지 않고 식별하고, 관리 파일을 사용자 수정 손실 없이 원자적으로 적용·복구하며, CLI와 선택 MCP가 같은 typed 계약을 돌려주는 실행·저장 기반을 만든다. 이 영역이 서야 설치(EP-05)·맞춤 생성(EP-04)·claim(EP-07)이 같은 identity·receipt·protocol 위에서 돌아간다. 결과는 세 leaf(01-A resolver/identity, 01-B 적용·receipt, 01-C CLI/MCP parity)로 쪼개며 영역 Issue 자체는 owner를 갖지 않는다.

## 비목표와 범위
비목표: Go 세대 `.moai/`·`~/.moai/`·`$HOME/go/bin/moai`의 읽기·이동·삭제, 폴더명 `.moai-cli`→`.moai` 전환, SQLite·서버·공용 DB 도입, 다중 host 분산 lock, 자체 MCP 서버 상시 호스팅, Go 코드 포팅. 범위: `<project>/.moai-cli/`와 `~/.moai-cli/` 아래의 Rust 전용 상태, `src/*.rs`·`tests/product_cli.rs`·`docs/rust-product-path.md`, 그리고 skills/moai가 호출하는 내부 실행 계약. 미결 기술 선택(P05·P06·P09·P11 등)은 HOLD로 둔다.

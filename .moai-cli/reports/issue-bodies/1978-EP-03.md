# [RC1][EP-03] 공통 skill과 host

## 목표와 사용자 가치
사용자가 MoAI skill을 사용자 수준에서 한 번 추가하면 Claude Code와 Codex Desktop(및 지원표에 따라 ZCode)에서 같은 공통 package(동일 release·digest)를 각 host의 공식 발견 경로에서 찾고, host native 방식(`/moai`, `$moai`)으로 명시 호출해 READ·SETUP·UPDATE·PLAN·RUN·VERIFY·AUDIT·SYNC 8개 intent를 같은 workflow 계약으로 수행하게 한다. 이 영역은 (1) 단일 router와 lazy workflow/resource 재설계(02-A), (2) Claude 발견·호출·native(AGENTS/style/statusline/hook) 계약 검증(02-B), (3) Codex Desktop/CLI 발견·호출·sandbox·설정·hook 지원/제한 증거(02-C), (4) ZCode 공식 지원표와 adapter gap 기록(02-D)으로 나뉜다. 가치는 '파일이 생겼다'가 아니라 '실제 host가 읽고 호출했다'는 host별 증거(files_created·host_loaded·execution_verified 분리)를 남기는 데 있다.

## 비목표와 범위
비목표: 고정 전문 agent bundle 배포(D12), Claude 전용 frontmatter·도구명·`$ARGUMENTS`·동적 shell context를 공통 package에 그대로 넣기, `.claude/rules`를 Codex/ZCode가 자동 해석한다고 가정하기, host trust·permission·hook·MCP 등록을 파일 생성에 묶어 확대하기, Go 세대 `.moai/`·`~/.moai/`·설치본·원격 `main` 변경, Z.ai ZCode를 공식 문서·실측 없이 '지원'으로 표기하기, 인터뷰·맞춤 생성(EP-04)·설치/UPDATE 본체(EP-05)의 구현. 범위: `skills/moai/**` 공통 package 재설계와 검증, host별 발견/호출 adapter 계약과 capability 기록(`host-capabilities` 모델), 지원표. 선택 기능(statusline·output style·hooks)은 opt-in이며 RC1 필수 gate는 두 host의 발견·명시 호출·SETUP routing·세션 UPDATE 실행이다(설계 00 §24).

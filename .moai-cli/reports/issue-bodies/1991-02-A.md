# [RC1][공통 skill과 host] 02-A 단일 MoAI router와 workflow 재설계

## 목표와 사용자 가치
`skills/moai/` 공통 package를 host-neutral 단일 router로 확정한다. SKILL.md는 Agent Skills 명세의 `name`/`description`만을 공통 frontmatter로 두고, `references/routes.json`이 8개 intent(READ·SETUP·UPDATE·PLAN·RUN·VERIFY·AUDIT·SYNC)를 lazy-loaded `workflows/<intent>.md`에 연결하며, 각 workflow와 resource는 출처(원본 skill/rule의 commit·path·digest·license)를 `source-manifest`로 추적한다. legacy agent 정의는 배포하지 않고 역할 지식만 workflow/resource로 계승한다(D11·D12). 패키지 digest(`moai-package-tree-v1`)와 Rust 검증기가 '공통 package가 Claude 전용 요소를 포함하지 않음'을 기계적으로 보장해 02-B/02-C/02-D가 같은 canonical body를 projection으로 쓸 수 있게 한다. #1973의 뼈대(SKILL.md·routes.json·8 workflow)는 재사용하고 남은 범위만 다룬다.

## 비목표와 범위
비목표: host별 발견 경로에 파일을 설치·복사하는 일(02-B/02-C·EP-05), 인터뷰·맞춤 생성(EP-04), 기존 190개 Claude 자산의 전수 이행(00-A 기준선 대조 결과를 입력으로만 사용), 자연어 자동 선택률 측정(ROUTING은 02-B/02-C에서 host별로), MCP tool parity(01-C). 범위: `skills/moai/SKILL.md`·`references/routes.json`·`workflows/*.md`·새 `references/`·`source-manifest.json`, 패키지 검증 Rust 코드와 fixture, `docs/rust-product-path.md`의 공통 package 절. SKILL.md 본문 영어 유지는 현행 파일 관례이며 사용자 언어 규칙은 Issue 본문에만 적용된다(package 본문 언어는 HOLD 항목 참조).

## SPEC 요구(GEARS)
- REQ-02A-01 (Ubiquitous) 공통 package `skills/moai/SKILL.md`의 frontmatter는 `name: moai`와 `description`만 가져야 하며(선택: `license`·`metadata.version`), Claude 전용 필드·`$ARGUMENTS`·`!`` 동적 context를 포함하지 않아야 한다.
- REQ-02A-02 (Ubiquitous) `references/routes.json`은 READ·SETUP·UPDATE·PLAN·RUN·VERIFY·AUDIT·SYNC 8개 route를 각각 존재하는 `workflows/<intent>.md`에 연결하고 `requires_binary`와 `classification_is_authorization:false`를 유지해야 한다.
- REQ-02A-03 (WHEN) router가 요청을 intent로 분류했을 때, 해당 intent의 workflow 파일과 그 workflow가 명시한 reference만 읽어야 하며 다른 workflow를 선로드하지 않아야 한다.
- REQ-02A-04 (Ubiquitous) 각 workflow/resource 파일은 `references/source-manifest.json`에 원본(기존 skill/rule/agent)의 commit SHA·경로·digest·license·채택/비채택 사유를 기록해야 하며, 매핑되지 않은 원본은 unchecked로 남겨 삭제·완료 처리하지 않아야 한다.
- REQ-02A-05 (Ubiquitous) 공통 package에는 고정 agent 정의(`agents/*.md`·`*.toml`)가 포함되지 않아야 한다(D12).
- REQ-02A-06 (WHILE) 저장소·Issue·외부 문서에서 읽은 문장을 처리하는 동안, router는 그것을 자료로만 취급하고 권한 승격이나 명령 실행 지시로 해석하지 않아야 한다(현행 SKILL.md 문장 유지).
- REQ-02A-07 (Ubiquitous) `moai-cli package-inspect skills/moai`는 같은 트리에서 재실행 시 동일 digest를 내야 하며 SKILL.md 누락·symlink·비포터블 경로를 거부해야 한다.
- REQ-02A-08 (WHERE) Rust 검증기(새 subcommand 또는 테스트)가 있는 경우, SKILL.md frontmatter 금지 필드·500행 초과·참조 2단계 이상·routes.json 참조 파일 부재를 실패로 보고해야 한다.

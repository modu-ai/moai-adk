# [RC1][Forge 보고와 판단 context] 07-C 간결 보고와 artifact 참조 구현

## 목표와 사용자 가치
실행 결과를 Issue에 '소유 보고 댓글 하나'로 간결하게 반영하는 `moai-cli forge-report PROJECT --permission-reference R`를 구현한다. 입력은 05-D의 audit verdict·검증 receipt(명령·revision·exit·상태)와 다음 작업이며, 출력은 설계 22 `issue-report` 템플릿(`MoAI run / 상태 / 수행 내용 / 시험 결과 / 다음 작업 / 근거 / 상세 로그`)을 렌더링한 댓글이다. stable run marker(`<!-- moai:report run=<stable_run_id> -->`)로 기존 댓글을 찾아 PATCH로 갱신하고, 없을 때만 POST한다. 대형 로그·snapshot은 본문에 넣지 않고 digest·크기·위치·보존기한·접근 범위를 가진 artifact 참조로 남긴다. 사용자 가치: Issue가 읽기 쉬운 원장으로 유지되고, not_run·failed·blocked가 성공으로 둔갑하지 않으며, timeout 뒤에도 중복 댓글이 생기지 않는다.

## SPEC 요구(GEARS)
- REQ-REPORT-001 Ubiquitous 보고 payload는 `schema_version`, `stable_run_id`, `issue: ExternalRef`, `status(running|blocked|review|done)`, `work`, `checks[]{name, command, revision, exit_code, result(passed|failed|not_run|blocked|stale|unknown)}`, `gaps`, `next`, `evidence_links[]`, `artifacts[]`를 가져야 한다.
- REQ-REPORT-002 WHEN `status: done`을 쓰려면 모든 `required: true` check의 result가 `passed`이고 revision이 현재 candidate SHA와 같아야 하며, 아니면 렌더러가 거부해야 한다.
- REQ-REPORT-003 Ubiquitous 렌더링 본문 첫 줄은 `<!-- moai:report run=<stable_run_id> -->`이고 둘째 줄은 `MoAI run: <stable_run_id>`여야 한다.
- REQ-REPORT-004 WHEN 게시 전 같은 Issue의 댓글을 `since` 없이 전체 페이지네이션으로 읽어 marker 댓글이 있으면 PATCH로 갱신하고, 없을 때만 POST해야 한다.
- REQ-REPORT-005 WHEN 기존 marker 댓글의 본문 digest가 outbox에 기록된 마지막 게시 digest와 다르면(사람 편집) 덮어쓰지 않고 `conflict`를 반환하고 새 댓글 제안만 로컬에 남겨야 한다.
- REQ-REPORT-006 WHEN POST/PATCH가 timeout·연결 유실이면 outbox 항목을 `publish_unknown`으로 두고, 다음 실행에서 marker 재조회 후에만 재시도해야 한다(중복 댓글 0).
- REQ-REPORT-007 Ubiquitous 본문에 포함되는 모든 문자열은 redaction 게이트(보수적 비밀 모양 필터 + 제어문자 제거)를 통과해야 하며, 실패 시 게시하지 않고 `blocked_sensitive`를 반환해야 한다.
- REQ-REPORT-008 Ubiquitous 검증 명령 출력은 본문에 넣지 않고 `checks[].exit_code`와 ≤N줄 tail(기본 N은 설정, P11)만 넣으며, 전체 출력은 artifact 참조로만 가리켜야 한다.
- REQ-REPORT-009 Ubiquitous artifact 참조는 `kind(local|actions_artifact|release_asset|issue_artifact|external)`, `digest(sha256)`, `size_bytes`, `location`, `retention(until|unknown)`, `access(public|repo|private)`, `redacted: bool`을 포함해야 하며 `location`만 있고 digest가 없는 참조는 거부해야 한다.
- REQ-REPORT-010 WHERE artifact 저장소가 미결(P09)이면 `kind: local`로 `<project>/.moai-cli/evidence/<run>/`에 보존하고 보고 본문에 'export/pin 필요'를 표시해야 한다.
- REQ-REPORT-011 Ubiquitous 렌더링 본문 길이는 설정 상한(기본값 P11; 상한 미결 시 65,536자 미만을 보수적 기본)으로 제한하고 초과 시 게시 대신 `too_large`를 반환해야 한다.

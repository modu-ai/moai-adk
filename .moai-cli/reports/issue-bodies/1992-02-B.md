# [RC1][공통 skill과 host] 02-B Claude 발견 호출과 native adapter 검증

## 목표와 사용자 가치
Claude Code에서 공통 package의 projection(`~/.claude/skills/moai/SKILL.md` 또는 선택 시 `.claude/skills/moai/SKILL.md`)이 공식 경로에서 발견되고 `/moai`로 명시 호출되어 canonical body와 reference가 실제 로드됨을 host 증거로 확인한다. 함께 (1) AGENTS.md 로딩 조건(v2.1.277+, CLAUDE 계열 파일 억제, `/config` Project instructions, `/memory` 확인)을 doctor 수준으로 진단해 `host-capabilities`에 기록하고, (2) output style·statusline·최소 hook의 Claude 계약(settings.json 키·stdin JSON·exit/decision 의미)을 adapter 계약으로 고정하되 opt-in·사용자 설정 보존·전체 교체 금지를 지킨다. 결과는 `files_created`·`host_loaded`·`execution_verified`를 분리해 보고한다(HA-01·HA-03·HA-05·HA-08).

## 비목표와 범위
비목표: 사용자 홈 설치본의 실제 설치·UPDATE 흐름(EP-05 04-A/04-B), 새 CLAUDE.md 생성이나 기존 CLAUDE 파일 삭제, `~/.claude/settings.json` 전체 교체, hook 전수(96개) 이식, 자연어 자동 선택률 최적화(ROUTING은 측정만), cloud 세션 인증(관측 기록만). 범위: Claude adapter 계약 정의(discovery/invocation/AGENTS 진단/style/statusline/hook 최소 집합)와 그 검증 fixture, Claude 전용 projection 규칙(frontmatter 추가분), `host-capabilities` 기록, 기존 provisional Python adapter(`adapters/claude/`)의 유지/대체 판단(HOLD).

## SPEC 요구(GEARS)
- REQ-02B-01 (Ubiquitous) Claude projection `SKILL.md`는 02-A canonical body와 바이트 동일한 본문을 갖고, frontmatter는 `name: moai`·`description`에 Claude 전용 필드를 추가할 때만 확장하며 그 추가분을 projection manifest에 기록해야 한다.
- REQ-02B-02 (WHEN) 사용자가 Claude Code 세션에서 `/moai`를 호출했을 때, adapter 검증은 `/skills`(또는 `/` 메뉴) 목록·실제 로드된 SKILL.md 경로·reference 읽기 흔적을 receipt로 남겨야 하며 파일 존재만으로 `host_loaded:true`를 기록하지 않아야 한다.
- REQ-02B-03 (WHERE) 세션 시작 시 존재하지 않던 `~/.claude/skills/` 또는 `.claude/skills/`를 새로 만든 경우, adapter는 `/reload-skills` 필요를 결과에 표시해야 한다.
- REQ-02B-04 (Ubiquitous) doctor는 `claude --version`≥2.1.277, CWD/상위의 `CLAUDE.md`·`.claude/CLAUDE.md`·`CLAUDE.local.md` 존재, Project instructions 설정값을 확인해 AGENTS.md 로딩 상태를 `loaded|suppressed_by_claude_md|unsupported_version|unknown`으로 기록해야 하며 기존 CLAUDE 파일을 삭제·생성하지 않아야 한다.
- REQ-02B-05 (IF) AGENTS.md가 CLAUDE 파일로 억제되면, adapter는 `@AGENTS.md` import 또는 `claude-md-and-agents-md` 설정을 '제안'으로만 보고하고 사용자 승인 없이 파일·settings를 바꾸지 않아야 한다.
- REQ-02B-06 (WHERE) output style projection을 선택한 경우, `.claude/output-styles/<id>.md`를 생성하되 `outputStyle` 키를 자동 설정하지 않고(never auto-selected), 기존 사용자 style 파일을 덮어쓰지 않아야 한다. MoAI-Learn 계열은 `keep-coding-instructions:false`를 보존해야 한다.
- REQ-02B-07 (WHERE) statusline을 선택한 경우, settings의 `statusLine` 키만 관리 병합하고 renderer는 stdin JSON 필드(`model.display_name`·`context_window.used_percentage`·`cost.*`·`workspace.*`)만 읽으며 provider secret을 로드하지 않아야 한다. 기존 사용자 statusLine이 있으면 conflict로 보고해야 한다.
- REQ-02B-08 (Ubiquitous) MoAI 제공 hook은 opt-in 최소 집합만 settings의 관리 handler로 추가하고 사용자 hook 배열·matcher·unknown key를 보존해야 하며, `PermissionRequest` 결정 없음·exit 0을 allow로 해석하지 않아야 한다.
- REQ-02B-09 (Ubiquitous) 결과 schema는 `files_created`·`host_loaded`·`execution_verified`를 분리하고 미실행은 `not_run`, 권한 거부는 `denied`로 기록해야 한다.

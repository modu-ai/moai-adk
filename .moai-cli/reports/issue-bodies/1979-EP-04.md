# [RC1][EP-04] 최초 설정과 맞춤 생성

## 목표와 사용자 가치
사용자가 Claude Code 또는 Codex에서 `/moai 프로젝트 설정 해줘`라고 한 번 요청하면, 저장소를 읽고 최초 1회 딥 인터뷰를 거쳐 작은 portable profile(`.moai-cli/project.yaml`)을 만들고, 프로젝트와 관련된 외부 skill을 출처·revision·license가 확인된 상태로 host 공식 폴더에 설치해 전부 읽은 뒤, 그 결과로 AGENTS 관리 구간·portable workflow·선택 native 역할 파일을 3-way 보존 병합으로 생성한다. 같은 입력으로 다시 실행하면 diff 0이고, 사용자 원본은 바이트 단위로 보존된다. 이 영역이 끝나면 SETUP 경로(SETUP-02~05)가 Rust 실행 계층에서 실제로 동작하는 증거가 남는다.

## 비목표와 범위
범위: 03-A(profile·재설정), 03-B(외부 skill 후보·provenance·공식 폴더 설치·전체 읽기 receipt), 03-C(generation plan·3-way merge·rerun diff 0·선택 native 역할). 비범위: host 발견·명시 호출 검증(02-B/02-C), 설치·UPDATE·부분 실패 복구(04-x), `.claude/settings.json`·`.codex/config.toml`의 native 기능 활성화(hook·statusline 등은 02-B/04-B 소유, 03-C는 HOLD), script 실행·네트워크 전송 승인, publisher 신뢰 보증, Go `.moai/`·`~/.moai/`와 사용자 자료 변경, 원격 `main` 변경. 선행 완료 #1973(Profile v1, `agents-plan/apply`, `skills/moai` 뼈대)은 재사용하고 남은 범위만 다룬다.

## SPEC 요구(GEARS)
- REQ-00A-01 WHEN 기준선 수집을 실행하면, 도구는 현재 checkout의 HEAD SHA(40 hex)·현재 브랜치·`git worktree list --porcelain` 전체·`git ls-remote --heads origin` 결과·수집 시각(UTC)을 하나의 기준선 레코드(`schema_version: 1`)에 기록해야 한다.
- REQ-00A-02 WHEN 기준선 수집을 실행하면, 도구는 tracked 변경 파일과 untracked 파일을 `git status --porcelain=v2 -z --untracked-files=all` 기준으로 열거하고 각 파일의 sha256(`sha256:<64hex>`)과 git object name(있는 경우)을 함께 기록해야 한다.
- REQ-00A-03 WHERE Go 기준선 커밋 4fa2aa9db2e0add0f1299e35407141b2b41c5ec0이 로컬 object store(moai-adk 또는 moai-adk-go)에 존재하면, 도구는 `git ls-tree -r` 읽기만으로 `.claude/**`와 `internal/template/templates/**/.claude/**` 경로·blob id를 열거해야 하며 checkout·reset·fetch를 수행해서는 안 된다.
- REQ-00A-04 WHEN 세 집합(Go 기준선 `.claude`, Go template `.claude`, 현재 checkout 설치본 `.claude/`)을 비교하면, 도구는 각 경로를 정확히 한 분류(동일·상이·template-only·active-only·baseline-only)와 tracked/untracked·source/generated·private/shared 태그로 표기한 차이표를 생성해야 하고 미분류 경로는 0이어야 한다.
- REQ-00A-05 WHILE 수집이 진행되는 동안, 도구는 `.claude/`·`.moai/`·`~/.moai/`·`/Users/goos/moai/moai-adk-go/**`·`AGENTS.md`의 어떤 바이트도 변경해서는 안 되며(쓰기 open 금지), 수집 전후 보존 대상 해시 목록이 `shasum -a 256 -c --strict --status`로 exit 0이어야 한다.
- REQ-00A-06 IF 동일 입력(같은 HEAD·같은 작업 트리)으로 두 번 실행하면, THEN 수집 시각 필드를 제외한 산출물은 byte-identical이어야 한다.
- REQ-00A-07 WHEN 차이표에 수치(파일 수 등)를 적을 때, 도구는 측정 명령과 측정 시각을 함께 기록해야 하며 문서상 수치('190' 등)를 측정 없이 재기입해서는 안 된다.
- REQ-00A-08 WHERE 사용자 홈 경로(`~/.claude`, `~/.moai`, `~/.agents`)가 포함 대상으로 결정(HOLD-00A-2)되기 전에는, 도구는 홈 디렉터리를 열거·해시하지 않아야 하며 존재 여부만 기록할 수 있다.
- REQ-00A-09 WHEN 산출물을 기록하면, 도구는 절대 경로·사용자 이름·토큰 형태 문자열을 tracked 산출물에 포함하지 않아야 하고 경로는 저장소 상대 경로로 적어야 한다.

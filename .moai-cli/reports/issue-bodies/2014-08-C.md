# [RC1][RC 인증과 문서] 08-C RC host OS E2E와 restore

## 목표와 사용자 가치
Claude Code와 Codex 두 host에서 공통 skill `moai`가 실제로 발견·명시 호출되고, SETUP → UPDATE → (중단·거부·충돌) → restore가 실제 OS 환경에서 완주되는지 E2E로 검증하고, 그 결과를 조합(OS/arch × host × exact version × mode)별 증거로 남긴다. 사용자 가치: '파일이 설치됐다'가 아니라 '이 조합에서 실제로 동작했고 사용자 파일이 보존됐으며 중단 후 복구됐다'는 증거가 지원표(08-D)의 유일한 입력이 된다. 양 host 모두 필수이며 Claude-only로 대체할 수 없다(12-page §1).

## 비목표와 범위
범위: 3단 E2E — (T1) host 없이 임시 HOME·임시 프로젝트에서 `moai-cli`로 SETUP/UPDATE/중단/restore를 재현하는 결정적 fixture, (T2) 실제 host 로딩 E2E(`claude -p --bare --add-dir` / `codex exec --json`)로 skill 발견·명시 호출·workflow 진입 확인, (T3) OS matrix(HOLD, P12). restore 시험: 중단된 UPDATE의 journal 기반 known-good 복구, 사용자 편집 보존, digest 불일치 fail-closed, 권한 거부 유지. 비범위: Go 세대 설치본 전환·제거(D79, RL-COMMAND-CUTOVER는 후속), Desktop(M5), ZCode·기타 host(02-D), 서명 artifact 설치 시험(08-D·04-A), 자체 서버. T2는 host 자격증명과 비용이 들어 CI 자동화 여부는 HOLD.

## SPEC 요구(GEARS)
- REQ-08C-01 [Ubiquitous] 각 E2E 실행은 `os`, `arch`, `host`, `host_exact_version`, `mode(local|worktree|cloud)`, `skill_digest`, `moai_cli_sha`, 결과(`passed|failed|not_run|blocked`)를 가진 receipt를 남겨야 하며, 이 receipt만이 지원표의 입력이어야 한다.
- REQ-08C-02 [WHERE] host가 없는 fixture 환경(T1)에서 시스템은 임시 `HOME`과 임시 프로젝트만 사용해야 하며 실제 `~/.claude`·`~/.agents`·`~/.moai`·`~/.moai-cli`에 쓰지 않아야 한다.
- REQ-08C-03 [WHEN] Claude Code에서 `/moai` 또는 자연어로 SETUP을 요청했을 때 시스템은 실제로 로드된 package digest를 보고해야 하며, 파일 존재·메뉴 표시만으로 PASS를 기록하지 않아야 한다(INVOKE).
- REQ-08C-04 [WHEN] Codex에서 `$moai`(또는 `/skills`)로 명시 호출했을 때 시스템은 같은 workflow 진입과 동일 digest를 보고해야 한다.
- REQ-08C-05 [WHILE] UPDATE 적용 중 프로세스가 중단되면 다음 실행에서 시스템은 journal/manifest로 실제 교체된 파일을 조회해 known-good으로 복구하거나 정직한 conflict를 남겨야 하며 사용자 편집을 덮지 않아야 한다(RL-03).
- REQ-08C-06 [IF-THEN] 다운로드/패키지 digest가 기대값과 다르거나 target이 맞지 않으면 시스템은 설치·적용을 거부(fail-closed)하고 blocked를 보고해야 한다(RL-07, HA-06).
- REQ-08C-07 [WHEN] host가 권한 요청을 거부했을 때 시스템은 다른 adapter로 재실행하지 않고 거부 상태를 유지·보고해야 한다(PERMISSION, HA-08).
- REQ-08C-08 [Ubiquitous] 같은 입력의 재실행은 diff 0이어야 한다(UPDATE 재요청 diff 0, HA-02).
- REQ-08C-09 [WHERE] MoAI binary가 없는 clean remote clone에서 시스템은 portable 자산으로 READ/PLAN을 수행하고 CLI 의존 gate는 not_run/blocked로 보고해야 한다(REMOTE-PORTABLE, HA-04).
- REQ-08C-10 [Ubiquitous] E2E 중 Go 세대 경로(`.moai/`, `~/.moai/`)와 Go 설치본의 해시는 변하지 않아야 한다(RL-GENERATION-ISOLATION).

## 인수 기준과 검증
- AC-08C-1 (T1 fixture, HA-02/RL-03): 임시 HOME·프로젝트에서 SETUP → UPDATE → 강제 중단 → 재실행 복구가 통과하고 사용자 편집 파일 해시가 보존됨 · 검증: `CARGO_HOME=/tmp/moai-rc-product-cargo CARGO_TARGET_DIR=/tmp/moai-rc-product-target HOME=$(mktemp -d) cargo test --offline --locked --test e2e_host_fixture -- --nocapture` · 결과: not_run
- AC-08C-2 (RL-07/HA-06): digest 불일치·잘못된 target 패키지는 적용 거부(exit 비 0, 파일 변경 0) · 검증: `cargo test ... e2e_digest_mismatch_is_fail_closed ; 대상 트리 shasum 전후 동일` · 결과: not_run
- AC-08C-3 (INVOKE, Claude): Claude Code가 `moai` skill을 실제 로드해 SETUP route를 탔음을 JSON 결과에서 확인 · 검증: `ANTHROPIC_API_KEY=<redacted> claude --bare -p '/moai 프로젝트 설정 미리보기만 해줘' --add-dir <tmp-project> --output-format json --permission-mode dontAsk --permission-prompts none | jq '.result, .session_id' (사전: <tmp-project>/.claude/skills/moai ← skills/moai 복사, digest 기록)` · 결과: not_run
- AC-08C-4 (INVOKE, Codex): Codex가 `$moai`를 명시 호출해 같은 route에 진입했음을 JSONL `turn.completed`와 최종 메시지로 확인 · 검증: `cd <tmp-project> && codex exec --json --ephemeral --ignore-user-config --sandbox read-only -o /tmp/codex-last.md '$moai 프로젝트 설정 미리보기만 해줘' ; grep -c '"type":"turn.completed"' (사전: <tmp-project>/.agents/skills/moai ← skills/moai 복사)` · 결과: not_run
- AC-08C-5 (skill 정적 유효성): 공통 skill이 Agent Skills 명세와 Claude 파서를 통과 · 검증: `claude plugin validate <tmp-project>/.claude/skills ; (선택) skills-ref validate skills/moai` · 결과: not_run
- AC-08C-6 (PERMISSION/HA-08): 권한 거부 시 blocked 보고, 미승인 mutation 0(대상 트리 해시 불변) · 검증: `claude --bare -p '/moai 설정 적용' --permission-mode dontAsk --permission-prompts none --output-format stream-json | jq 'select(.type=="result") | .permission_denials' ; shasum 전후 비교` · 결과: not_run
- AC-08C-7 (RL-GENERATION-ISOLATION): E2E 전후 `.moai/`·`~/.moai/`·Go 바이너리 해시 동일 · 검증: `find .moai ~/.moai -type f -print0 2>/dev/null | sort -z | xargs -0 shasum -a 256 > /tmp/go-before.txt ; (E2E) ; shasum -a 256 -c /tmp/go-before.txt ; shasum -a 256 $(command -v moai)` · 결과: not_run
- AC-08C-8 (HA-04): binary 없는 clean clone에서 READ/PLAN 가능, CLI gate는 not_run · 검증: `git clone --depth 1 <repo> /tmp/clean && cd /tmp/clean && PATH=/usr/bin:/bin claude --bare -p '/moai 현재 저장소 읽기' --output-format json | jq .result` · 결과: not_run
- AC-08C-9: 독립 AUDIT verdict PASS(별도 세션, receipt 직접 대조) · 검증: `별도 세션 감사 보고 링크 · audited_sha == candidate_sha` · 결과: not_run

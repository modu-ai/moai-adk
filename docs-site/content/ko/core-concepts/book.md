# 클로드 코드로 시작하는 실전 에이전틱 코딩

**바이브 코딩의 끝, 하네스 엔지니어링의 시작.** MoAI-ADK 메인테이너가 직접 쓴 488쪽 실무 가이드입니다. 이 문서의 사이트가 다루는 개념 — 토크노믹스, 에이전틱 루프 엔지니어링, 에이전틱 하네스 — 을 한 권의 책으로 체계적으로 펼쳐 놓았습니다.

## 이 책이 답하는 질문

이 사이트의 [세 가지 핵심 가치](/ko/core-concepts/what-is-moai-adk/) — 비용, 자가 개선, 품질 통제 — 가 한데 엮여 어떻게 현실의 개발 환경이 되는지를 책은 한 권으로 따라갑니다.

- **비용을 어떻게 시스템이 지키는가** — 작업마다 모델·추론 깊이를 배정하고, 컨텍스트를 다이어트하고, 예산 초과 전에 멈추는 일련의 과정.
- **루프가 어떻게 하네스를 개선하는가** — 관찰이 규칙이 되고, 규칙이 다음 실행을 더 똑똑하게 만드는 자가 진화 사이클.
- **"완료"를 어떻게 검증된 완료로 바꾸는가** — SPEC 3-단계와 TRUST 5 게이트, 그리고 관찰하지 않은 주장을 막는 [검증 주장 무결성](/ko/core-concepts/verification-claim-integrity/) 규칙.

[하네스 엔지니어링](/ko/core-concepts/harness-engineering/) 페이지에서 다루는 "Human steers, agents execute." 가 책 전체를 관통하는 철학입니다.

## 누가 읽으면 좋은가

- **에이전틱 코딩을 처음 시작하는 개발자** — 바이브 코딩의 낭비를 줄이고 구조적인 하네스 엔지니어링으로 옮겨가는 길을 한 권으로 따라갑니다.
- **팀 단위로 Claude Code 를 도입하려는 리더** — 비용 통제와 품질 게이트, 세션 연속성을 시스템으로 어떻게 쥐는지를 다룹니다.
- **MoAI-ADK 를 깊이 쓰고 싶은 사용자** — 이 사이트의 문서가 개념 단위라면, 책은 그 개념들이 어떻게 이어지는지를 실무 시나리오로 보여줍니다.

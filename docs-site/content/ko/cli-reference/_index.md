터미널에서 실행하는 `moai`(Go 바이너리) 커맨드의 상세 레퍼런스입니다. 각 커맨드의 플래그, 하위 명령어, 사용 예시를 다룹니다.

Claude Code 대화창에서 입력하는 슬래시 `/moai` 커맨드(워크플로우/유틸리티 명령어)와는 완전히 다른 도구입니다. 워크플로우 명령어는 [워크플로우 명령어](/workflow-commands), 유틸리티 명령어는 [유틸리티 명령어](/utility-commands) 섹션을 참조하세요. `moai` CLI 전체 개요는 [CLI 개요](/getting-started/cli)에서 확인할 수 있습니다.

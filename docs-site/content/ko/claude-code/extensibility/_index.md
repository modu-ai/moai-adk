이 그룹은 Claude Code의 기본 기능을 넘어 동작을 확장하는 네 가지 방법을 다룹니다. 스킬로 전문 지식을 모듈화하고, 훅으로 이벤트에 자동화를 걸고, MCP로 외부 도구를 연결하며, 플러그인으로 이 모든 것을 하나의 패키지로 배포하는 흐름을 개념 중심으로 설명합니다.

이 네 가지가 곧 **에이전틱 하네스** (Agentic Harness)를 짓는 재료입니다. 코드를 직접 쓰는 대신 에이전트가 잘 일할 환경을 설계한다는 하네스 엔지니어링에서, 스킬은 에이전트의 지식을, 훅은 결정적 규율을, MCP는 외부 세계와의 연결을, 플러그인은 그 조합의 배포 단위를 담당합니다. MoAI-ADK가 `moai init` 한 번으로 배포하는 것도, `/moai project`가 프로젝트 전용으로 생성하는 것도 결국 이 재료들의 조합입니다.

{{< callout type="info" >}}
**한 줄 요약**: 스킬·훅·MCP·플러그인이라는 네 가지 확장점을 이해하면, Claude Code를 프로젝트 고유의 하네스로 만들 수 있습니다.
{{< /callout >}}

## 학습 흐름

```mermaid
flowchart TD
    A[스킬<br/>전문 지식 모듈] --> B[훅 Hooks<br/>이벤트 기반 자동화]
    B --> C[MCP 서버<br/>외부 도구 연결]
    C --> D[플러그인과 마켓플레이스<br/>확장 패키지 배포]
```

가장 가벼운 확장점인 스킬부터 시작해, 자동화를 거는 훅, 외부 세계와 잇는 MCP, 마지막으로 이들을 묶어 배포하는 플러그인 순서로 읽는 것을 권장합니다. 스킬·훅·MCP는 MoAI-ADK 심화 문서로 깊이 연결되니 개념을 잡은 뒤 더 파고들면 됩니다.

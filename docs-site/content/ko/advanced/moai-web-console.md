# MoAI Web Console

터미널 마법사가 편집하는 것과 똑같은 프로필·프로젝트 설정을 브라우저에서 고치는 방법이 **MoAI Web Console** 입니다. `moai web` 명령 하나로 콘솔이 뜨고, 마우스로 값을 바꾸면 터미널 마법사와 같은 유효성 검사를 거쳐 저장됩니다. YAML 파일을 직접 손으로 고치는 것보다 빠르고, 실수가 줄어듭니다.

![MoAI Web Console — 헤더의 프로젝트 이름과 프로필, 프로필 카드, 여섯 개 설정 탭](/img/moai-web-console.png)

## 무엇에 쓰는가

웹 콘솔은 두 종류의 설정을 편집합니다.

### 프로필 선호도 편집

모델·추론 강도·언어·표시 설정 등 프로필별 값을 고칩니다. 한 프로젝트에서 여러 프로필을 쓸 때 — 예컨대 평소엔 `medium`, 어려운 작업엔 `max` — 프로필 카드에서 전환하고 각 프로필의 세부 값을 탭에서 조정합니다.

### 프로젝트 섹션 편집

`.moai/config/sections/` 아래의 user / language / statusline 섹션을 웹 UI 에서 고칩니다. 터미널에서 YAML 을 편집기로 열지 않아도 됩니다.

저장할 때 터미널 마법사(`moai profile`) 와 같은 유효성 검사를 거치므로, 어느 쪽으로 고쳐도 결과는 같습니다. 마법사가 익숙한 사용자는 마법사로, 한눈에 보는 화면이 편한 사용자는 콘솔로 — 같은 설정 파일을 편집합니다.

## 4-로케일 UI

콘솔의 인터페이스 언어는 헤더 오른쪽 선택기에서 **English · 한국어 · 日本語 · 中文** 가운데 고릅니다. MoAI-ADK 가 지원하는 네 언어와 같습니다. 한국어를 고르면 메뉴·라벨·도움말이 모두 한국어로 바뀝니다. docs-site 의 [4-로케일 문서](/ko/resources/i18n-docs/) 와 같은 언어 세트로, 사용자의 모국어로 설정을 검사할 수 있습니다.

## 시작하기

프로젝트 디렉터리에서 명령 하나로 콘솔을 엽니다.

```bash
moai web
```

기본적으로 `127.0.0.1:3041` 에 바인딩되고 브라우저가 자동으로 열립니다. 포트가 이미 다른 moai 인스턴스가 쓰고 있으면 그 인스턴스를 종료하고 다시 바인딩합니다. moai 가 아닌 외부 프로세스가 포트를 쓰고 있으면 종료하지 않고 오류를 내며, 이때는 `--port` 로 다른 포트를 씁니다.

```bash
moai web --port 9000     # 다른 포트에 바인딩
moai web --no-open       # 브라우저를 열지 않고 시작
```

세부 플래그와 동작은 [CLI 레퍼런스 — moai web](/ko/cli-reference/web/) 에 있습니다.

## 보안 모델

웹 콘솔은 로컬 개발 편의를 위해 만들어졌고, 보안은 거기에 맞춰 설계되었습니다.

### 루프백 전용 (loopback-only)

콘솔은 **`127.0.0.1` 에만 바인딩** 됩니다. 외부 네트워크 인터페이스로 노출되지 않습니다. 같은 머신의 다른 사용자 계정이나 원격 호스트에서는 접근할 수 없습니다.

### 데이터베이스 없음 (no-DB)

별도의 데이터베이스 서버를 띄우지 않습니다. 콘솔이 읽고 쓰는 값은 현재 프로젝트의 설정 파일(`.moai/config/sections/`) 과 프로필 파일뿐입니다. 콘솔을 끄면 남는 것은 사용자가 저장한 설정 파일 변경뿐입니다.

### 인증 없음 (no-auth)

로컬 사용자 본인 이외에는 접근하지 못하므로(루프백 전용), 로그인이나 토큰 같은 인증 계층이 없습니다. 복잡한 자격증명 관리 없이 바로 씁니다.

{{< callout type="info" >}}
**루프백 전용이 인증 없음의 전제입니다.** 콘솔을 역방향 프록시나 `0.0.0.0` 바인딩으로 외부에 노출하는 설정은 공식적으로 지원하지 않습니다. 원격 편집이 필요하면 SSH 터널로 로컬 포트를 안전하게 전달하세요.
{{< /callout >}}

## 프로필 기록의 범위

콘솔에서 프로필을 전환하면 그 선택이 `~/.moai/claude-profiles/launch.yaml` 에 현재 프로젝트의 기록으로 남습니다. 같은 프로젝트에서 `-p` 없이 `moai cc` 를 실행할 때 이 값이 쓰입니다. 콘솔이 읽는 값과 쓰는 값은 모두 현재 프로젝트를 기준으로 하므로, 화면에 보이는 프로필과 실제로 기록되는 프로필은 언제나 같습니다.

선택 순서와 제약은 [프로필 관리](/ko/cli-reference/profile/) 에서 자세히 다룹니다.

## 언제 터미널 마법사를 쓰고 언제 콘솔을 쓸까

같은 설정 파일을 다루지만, 작업 흐름에 따라 어느 쪽이 편한지가 다릅니다.

- **터미널 마법사** (`moai profile`, `moai update -c`) — 한 값씩 단계적으로 고치는 초기 설정, CI 에서 스크립트로 돌리는 설정, 인터랙티브한 안내가 필요할 때.
- **웹 콘솔** (`moai web`) — 여러 섹션을 한 화면에서 비교하며 고칠 때, 프로필을 자주 전환하며 값을 비교할 때, YAML 들여쓰기를 신경 쓰지 않고 빠르게 바꾸고 싶을 때.

저장 결과는 같습니다. 자신에게 편한 쪽을 고르세요.

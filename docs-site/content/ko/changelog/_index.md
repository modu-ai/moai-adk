MoAI-ADK의 릴리스 노트는 **GitHub Releases**에서 관리합니다. 이 주소로 들어오면 그쪽으로 바로 연결됩니다.

- [GitHub Releases](https://github.com/modu-ai/moai-adk/releases) — 버전별 릴리스 노트(영어·한국어)와 배포 산출물
- [CHANGELOG.md](https://github.com/modu-ai/moai-adk/blob/main/CHANGELOG.md) — 전체 변경 이력(영어)

릴리스 노트를 문서 사이트에 따로 옮겨 적지 않는 이유는 단순합니다. 릴리스할 때마다 4개 언어로 옮겨 적으면 원본과 어긋나기 쉽고, GitHub Releases에는 릴리스 과정에서 영어·한국어 본문이 이미 함께 올라가기 때문입니다.

버전 번호는 [유의적 버전](https://semver.org/lang/ko/)을 따르고, 항목 구성은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/) 형식을 따릅니다.

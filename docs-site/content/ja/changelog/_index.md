MoAI-ADK のリリースノートは **GitHub Releases** で管理しています。このアドレスはそちらへリダイレクトされます。

- [GitHub Releases](https://github.com/modu-ai/moai-adk/releases) — バージョンごとのリリースノート (英語・韓国語) と配布物
- [CHANGELOG.md](https://github.com/modu-ai/moai-adk/blob/main/CHANGELOG.md) — 変更履歴の全体 (英語)

ドキュメントサイトに書き写さない理由は単純です。リリースのたびに 4 言語へ書き写すと原本とずれやすく、GitHub Releases にはリリース工程で英語・韓国語の本文がすでに揃っているからです。

バージョン番号は [セマンティック バージョニング](https://semver.org/lang/ja/) に、項目の構成は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) の形式に従います。

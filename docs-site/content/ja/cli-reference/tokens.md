Claude Code セッションのトークン使用量を**プール(pool)と出所(origin)別に分けて**記録する会計ツールです。「このカードにトークンをどれだけ使ったか」をセッション全体の合計ひとつだけで見ると、どのバックエンドがどれだけ使ったか・メイン対話とサブエージェントのサイドチェーンがそれぞれどれだけ使ったかが埋もれます。このコマンドはその2つを分けて残します。

{{< callout type="info" >}}
**一行要約**: `moai tokens record` がセッショントランスクリプトを読み、プール別(glm/claude/other)・出所別(メイン対話/サブエージェントのサイドチェーン)の使用量を集計し、コンテキスト使用スナップショットを添えて `.moai/state/token-accounting.jsonl` に1行で append します。
{{< /callout >}}

## 使い方

```bash
# 開いている/直前のセッショントランスクリプトを指定して記録
$ moai tokens record --transcript <パス> --card t12 --role run

# セッション id で指定
$ moai tokens record --session <セッション-ID> --card t12

# レコードを JSON で出力 (ファイル記録と一緒に)
$ moai tokens record --transcript <パス> --json
```

| フラグ | 説明 |
|--------|------|
| `--transcript <パス>` | 集計する Claude Code トランスクリプトファイル |
| `--session <id>` | セッション識別子でトランスクリプトを指定 |
| `--card <カード>` | この使用量を束ねるカンバンカード(例: `t12`) |
| `--role <役割>` | セッションの役割(例: `run`, `sync`, `worker-3`) |
| `--json` | 標準出力にもレコードを JSON で出力します |

## 記録の姿

レコードは `.moai/state/token-accounting.jsonl` に**append-only**で積まれます — セッション·カードが閉じるときに1行ずつ残す帳簿です。各行には:

- **プール別使用量** — `glm` / `claude` / `other` に分かれた合計。どのバックエンドが請求書を作ったかがプールからすぐ見えます。
- **出所別使用量** — メイン対話とサブエージェントのサイドチェーン。ワーカーを複数立てたランで「肝心の実装はワーカーがすべて使ったのか」を判別させます。
- **コンテキストスナップショット** — 記録時点にそのセッションのコンテキスト使用状態(`.moai/state/context-usage/<session-id>.json`)があれば、その値が一緒に入ります。

## いつ記録するか

設計上、カードまたはセッションが**閉じる時点**の記録です。カンバンランではカードが1枚終わるたびに、単一セッションでは大きな作業が終わったときに残せば、カードごとの費用比較が成立します。このコマンド自体はトークンを消費しません — すでに発生した使用量をトランスクリプトから数え直す会計です。

# MoAI Web Console

ターミナルウィザードが編集するのと同じプロファイル・プロジェクト設定をブラウザで修正する方法が**MoAI Web Console**です。`moai web`コマンド1つでコンソールが起き、マウスで値を変更するとターミナルウィザードと同じ有効性検証を経て保存されます。YAMLファイルを直接手作業で修正するよりも高速で、ミスも減ります。

![MoAI Web Console — ヘッダーのプロジェクト名とプロファイル、プロファイルカード、6つの設定タブ](/img/moai-web-console.png)

## 何に使うか

Webコンソールは2種類の設定を編集します。

### プロファイル嗜好編集

モデル・推論強度・言語・表示設定などプロファイルごとの値を修正します。1つのプロジェクトで複数のプロファイルを使うとき — 例えば普段は`medium`、難しい作業では`max` — プロファイルカードで切り替え、各プロファイルの詳細値をタブで調整します。

### プロジェクトセクション編集

`.moai/config/sections/`以下の user / language / statusline セクションをWeb UIで修正します。ターミナルでYAMLをエディタで開く必要がありません。

保存するときターミナルウィザード（`moai profile`）と同じ有効性検証を経るので、どちらで修正しても結果は同じです。ウィザードに慣れているユーザーはウィザードで、一覧で見える画面が便利なユーザーはコンソールで — 同じ設定ファイルを編集します。

## 4ロケイルUI

コンソールのインターフェース言語はヘッダー右側のセレクターで**English · 한국어 · 日本語 · 中文**の中から選べます。MoAI-ADKがサポートする4つの言語と同じです。韓国語を選ぶとメニュー・ラベル・ヘルプがすべて韓国語に変わります。ドキュメントサイトの[4ロケイルドキュメント](/ja/resources/i18n-docs/)と同じ言語セットで、ユーザーの母語で設定を検査できます。

## 始め方

プロジェクトディレクトリでコマンド1つでコンソールを開きます。

```bash
moai web
```

デフォルトでは`127.0.0.1:3041`にバインドされ、ブラウザが自動的に開きます。ポートが既に別のmoaiインスタンスが使っているならそのインスタンスを終了して再バインドします。moaiでない外部プロセスがポートを使っているなら終了せずにエラーを出し、そのときは`--port`で別のポートを使います。

```bash
moai web --port 9000     # 別のポートにバインド
moai web --no-open       # ブラウザを開かずに起動
```

詳細フラグと動作は[CLIリファレンス — moai web](/ja/cli-reference/web/)にあります。

## セキュリティモデル

Webコンソールはローカル開発利便性のために作られており、セキュリティはそれに合わせて設計されました。

### ループバック専用 (loopback-only)

コンソールは**`127.0.0.1`にのみバインド**されます。外部ネットワークインターフェースには公開されません。同じマシンの別のユーザーアカウントやリモートホストからはアクセスできません。

### データベースなし (no-DB)

別途データベースサーバーを立ち上げません。コンソールが読み書きする値は現在のプロジェクトの設定ファイル（`.moai/config/sections/`）とプロファイルファイルだけです。コンソールを終了すると残るのはユーザーが保存した設定ファイル変更だけです。

### 認証なし (no-auth)

ローカルユーザー本人以外はアクセスできないため（ループバック専用）、ログインやトークンのような認証レイヤーがありません。複雑な資格証明管理なしですぐに使えます。

{{< callout type="info" >}}
**ループバック専用が認証なしの前提です。** コンソールをリバースプロキシや`0.0.0.0`バインディングで外部に公開する設定は公式にはサポートしていません。リモート編集が必要ならSSHトンネルでローカルポートを安全に転送してください。
{{< /callout >}}

## プロファイル記録の範囲

コンソールでプロファイルを切り替えるとその選択が`~/.moai/claude-profiles/launch.yaml`に現在のプロジェクトの記録として残ります。同じプロジェクトで`-p`なしで`moai cc`を実行するときこの値が使われます。コンソールが読む値と書く値はすべて現在のプロジェクトを基準にするので、画面に見えるプロファイルと実際に記録されるプロファイルは常に同じです。

選択順序と制約は[プロファイル管理](/ja/cli-reference/profile/)で詳しく扱います。

## いつターミナルウィザードを使い、いつコンソールを使うか

同じ設定ファイルを扱いますが、作業フローによってどちらが便利かが異なります。

- **ターミナルウィザード** (`moai profile`、`moai update -c`) — 値を1つずつ段階的に修正する初期設定、CIでスクリプトで回す設定、インタラクティブなガイダンスが必要なとき。
- **Webコンソール** (`moai web`) — 複数のセクションを1画面で比較しながら修正するとき、プロジェクトを頻繁に切り替えて値を比較するとき、YAMLインデントを気にせず高速に修正したいとき。

保存結果は同じです。自分に便利な方を選んでください。

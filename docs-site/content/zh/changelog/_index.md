MoAI-ADK 的发布说明在 **GitHub Releases** 上维护。本地址会重定向到那里。

- [GitHub Releases](https://github.com/modu-ai/moai-adk/releases) —— 各版本的发布说明（英文）与构建产物
- [CHANGELOG.md](https://github.com/modu-ai/moai-adk/blob/main/CHANGELOG.md) —— 完整变更历史（英文）

不把发布说明抄进文档站的理由很简单：每次发布都要抄成四种语言，很容易与原文脱节；而 GitHub Releases 在发布流程中已经带上了英文正文。

版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)，条目结构遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 格式。

# MoAI Web Console

**MoAI Web Console** 是在浏览器中编辑与终端向导相同配置文件·项目设置的方法。一个 `moai web` 命令启动控制台,用鼠标修改值后会经过与终端向导相同的验证并保存。比直接手动编辑 YAML 文件更快,错误更少。

![MoAI Web Console — 头部的项目名称和配置文件,配置文件卡片,六个设置选项卡](/img/moai-web-console.png)

## 用途

Web 控制台编辑两种设置。

### 配置文件偏好编辑

修改模型·推理强度·语言·显示设置等各配置文件的值。在一个项目中使用多个配置文件时 — 例如平时用 `medium`,困难任务用 `max` — 在配置文件卡片中切换,在选项卡中调整每个配置文件的详细值。

### 项目部分编辑

在 Web UI 中编辑 `.moai/config/sections/` 下的 user / language / statusline 部分。不需要在终端用编辑器打开 YAML。

保存时经过与终端向导(`moai profile`)相同的验证,所以无论从哪边改结果都一样。熟悉向导的用户用向导,喜欢一目了然的画面用控制台 — 编辑相同的配置文件。

## 4-locale UI

控制台界面语言在头部右侧选择器中从 **English · 한국어 · 日本어 · 中文** 中选择。与 MoAI-ADK 支持的四种语言相同。选择韩语则菜单·标签·帮助全部变成韩语。与 docs-site 的 [4-locale 文档](/zh/resources/i18n-docs/) 相同的语言集,可以用母语检查设置。

## 开始

在项目目录中用一个命令打开控制台。

```bash
moai web
```

默认绑定到 `127.0.0.1:3041` 并自动打开浏览器。如果端口已被其他 moai 实例使用,则终止该实例并重新绑定。如果是 moai 以外的外部进程使用端口,则不终止并报错,此时用 `--port` 使用其他端口。

```bash
moai web --port 9000     # 绑定到其他端口
moai web --no-open       # 启动但不打开浏览器
```

详细标志和行为见 [CLI 参考 — moai web](/zh/cli-reference/web/)。

## 安全模型

Web 控制台为本地开发便利而创建,安全也相应设计。

### 仅环回(loopback-only)

控制台只绑定到 **`127.0.0.1`**。不暴露到外部网络接口。同一机器的其他用户账户或远程主机无法访问。

### 无数据库(no-DB)

不启动单独的数据库服务器。控制台读写的值只有当前项目的配置文件(`.moai/config/sections/`)和配置文件。关闭控制台后剩下的只有用户保存的配置文件变更。

### 无认证(no-auth)

只有本地用户本人能访问(仅环回),所以没有登录或令牌等认证层。没有复杂的资格证明管理,直接使用。

{{< callout type="info" >}}
**仅环回是无认证的前提。** 通过反向代理或 `0.0.0.0` 绑定将控制台暴露到外部的设置官方不支持。需要远程编辑则通过 SSH 隧道安全转发本地端口。
{{< /callout >}}

## 配置文件记录范围

在控制台中切换配置文件时,该选择会在 `~/.moai/claude-profiles/launch.yaml` 中记录为当前项目的记录。在同一项目中不带 `-p` 运行 `moai cc` 时使用这个值。控制台读取的值和写入的值都以当前项目为基准,所以画面上显示的配置文件和实际记录的配置文件始终相同。

选择顺序和约束见[配置文件管理](/zh/cli-reference/profile/)。

## 何时用终端向导,何时用控制台

处理相同配置文件,但根据工作流程哪边更方便不同。

- **终端向导**(`moai profile`、`moai update -c`) — 逐步逐个修改的初始设置,CI 中脚本运行的设置,需要交互式引导时。
- **Web 控制台**(`moai web`) — 在一个画面中比较并修改多个部分,频繁切换配置文件并比较值,不在意 YAML 缩进想快速修改时。

保存结果相同。选择自己方便的。

# MoAI Web Console

**MoAI Web Console** 是在浏览器中编辑与终端向导相同配置文件·项目设置的方法。一个 `moai web` 命令启动控制台,用鼠标修改值后会经过与终端向导相同的验证并保存。比直接手动编辑 YAML 文件更快,错误更少。

![MoAI Web Console — 头部的项目名称和配置文件,带有添加·重命名·删除控件的配置文件条,九个设置选项卡](/img/moai-web-console.png)

## 用途

Web 控制台编辑两种设置。

### 配置文件偏好编辑

修改模型·推理强度·语言·显示设置等各配置文件的值。在一个项目中使用多个配置文件时 — 例如平时用 `medium`,困难任务用 `max` — 在配置文件条(profile bar)中切换,在选项卡中调整每个配置文件的详细值。添加·重命名·删除控件就紧挨着选择器,因此配置文件的完整生命周期集中在一行 — 没有独立的配置文件管理卡片。

### 项目部分编辑

在 Web UI 中编辑 `.moai/config/sections/` 下的 user / language / statusline 部分。不需要在终端用编辑器打开 YAML。

保存时经过与终端向导(`moai profile`)相同的验证,所以无论从哪边改结果都一样。熟悉向导的用户用向导,喜欢一目了然的画面用控制台 — 编辑相同的配置文件。

## 控制台结构 — 九个选项卡

控制台按以下顺序分为九个选项卡。

1. **用户信息(Identity)** — 显示名称和项目级 identity 字段
2. **语言(Language)** — 对话·提交信息·代码注释·文档语言
3. **LLM** — 权限模式·模型·推理强度(会话启动时生效的三项)
4. **第三方 LLM(3rd Party LLM)** — 各层 GLM 模型选择、各层推理强度、GLM API 密钥
5. **工作流(Workflow)** — 执行模式·默认模式·agentic-loop·loop-prevention 设置
6. **Git·工作树(Git & Worktree)** — `git_strategy.mode`、各配置文件的 `merge_method` 三项、工作树·branch-guard 开关
7. **审计(Audit)** — 审计模型与各后端网关(claude / codex / glm)
8. **智能体(Agents)** — 各智能体的配置文件·模型分配
9. **报告(Report)** — 报告格式和输出偏好

选项卡列表是面板顺序的唯一来源 — 顶部看到的顺序与下方渲染的顺序一致。工作流·Git & 工作树·审计的拆分避免单个选项卡过于拥挤。此前这三个选项卡挤在一个工作流选项卡里,而 `git_strategy` 部分虽有字段定义却没有渲染表面,因此在 UI 中看不到 — 恢复该渲染表面是本次重新设计的一环。

### 控件诚实性

每个字段都按照其真实值域渲染合适的控件。

- **布尔字段** 不再渲染为复选框,而是一个二选一的单选组(使用 / 未使用)。复选框隐含"开关"的意味,但单选组显式呈现当前选择。
- **闭集字段** (`execution_mode`, `audit.model`, `harness.*` 等)渲染为 select 或单选组,保存时应用层会拒绝集合外的值。用自由文本接收闭集,就会给无效值留下入口 — 控制台不再提供这种入口。
- **真正开放的字段** (仓库路径、输出目录、GLM API 密钥)仍为自由文本 — 因为它们的值域确实是开放的。

### GLM 诚实徽章

在第三方 LLM 选项卡上,推理强度的运行时传递通道只有一个会话级环境变量 — 没有按层传递的路径。因此各层的推理强度值是 **仅存储(store-only)**:它们会保存到配置中,但运行时只读取会话级 effort 折叠到 z.ai 三状态后的值。选项卡上有一个徽章明确标注 **应用来源** (会话级 effort),使"各层值仅用于存储"这一点被明示,而不是被暗示。

## 4-locale UI

控制台界面语言在头部右侧选择器中从 **English · 한국어 · 日本어 · 中文** 中选择。与 MoAI-ADK 支持的四种语言相同。选择韩语则菜单·标签·帮助全部变成韩语。与 docs-site 的 [4-locale 文档](/zh/resources/i18n-docs/) 相同的语言集,可以用母语检查设置。

## 开始

在项目目录中用一个命令打开控制台。

```bash
moai web
```

默认绑定到 `127.0.0.1:3041` 并自动打开浏览器。如果端口已被其他 moai 实例使用,则终止该实例并重新绑定。如果是 moai 以外的外部进程使用端口,则不终止并报错,此时用 `--port` 使用其他端口。

```bash
moai web --port 9000     # 绑定到其他端口
moai web --no-open       # 启动但不打开浏览器
```

详细标志和行为见 [CLI 参考 — moai web](/zh/cli-reference/web/)。

## 安全模型

Web 控制台为本地开发便利而创建,安全也相应设计。

### 仅环回(loopback-only)

控制台只绑定到 **`127.0.0.1`**。不暴露到外部网络接口。同一机器的其他用户账户或远程主机无法访问。

### 无数据库(no-DB)

不启动单独的数据库服务器。控制台读写的值只有当前项目的配置文件(`.moai/config/sections/`)和配置文件。关闭控制台后剩下的只有用户保存的配置文件变更。

### 无认证(no-auth)

只有本地用户本人能访问(仅环回),所以没有登录或令牌等认证层。没有复杂的资格证明管理,直接使用。

{{< callout type="info" >}}
**仅环回是无认证的前提。** 通过反向代理或 `0.0.0.0` 绑定将控制台暴露到外部的设置官方不支持。需要远程编辑则通过 SSH 隧道安全转发本地端口。
{{< /callout >}}

## 配置文件记录范围

在控制台中切换配置文件时,该选择会在 `~/.moai/claude-profiles/launch.yaml` 中记录为当前项目的记录。在同一项目中不带 `-p` 运行 `moai cc` 时使用这个值。控制台读取的值和写入的值都以当前项目为基准,所以画面上显示的配置文件和实际记录的配置文件始终相同。

选择顺序和约束见[配置文件管理](/zh/cli-reference/profile/)。

## 何时用终端向导,何时用控制台

处理相同配置文件,但根据工作流程哪边更方便不同。

- **终端向导** (`moai profile`、`moai update -c`) — 逐步逐个修改的初始设置,CI 中脚本运行的设置,需要交互式引导时。
- **Web 控制台** (`moai web`) — 在一个画面中比较并修改多个部分,频繁切换配置文件并比较值,不在意 YAML 缩进想快速修改时。

保存结果相同。选择自己方便的。

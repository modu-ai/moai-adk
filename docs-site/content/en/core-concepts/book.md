## Questions This Book Answers

This site's [three core values](/en/core-concepts/what-is-moai-adk/) — cost, self-improvement, quality control — are woven together in one book to show how they become a real development environment.

- **How the system protects cost** — Assigning model·inference depth per task, dieting context, stopping before budget overflow — an entire process.
- **How loops improve the harness** — Observations becoming rules, rules making the next execution smarter — a self-evolution cycle.
- **How to turn "done" into verified done** — SPEC 3-phase and TRUST 5 gates, and the [Verification-Claim Integrity](/en/core-concepts/verification-claim-integrity/) rule preventing unobserved claims.

The [Harness engineering](/en/core-concepts/harness-engineering/) page's "Human steers, agents execute." philosophy runs through the entire book.
